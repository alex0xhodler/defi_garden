# 111 — PR explainer (HIGH tier)

## Goal
Human feedback on 093's shipped analytics nav: "the data and icons are very confusing" +
"these selectors need better hover overlay controls and UI for [the open-dropdown] state."
Two parts: (A) strip the per-tab category icons; (B) fix the open filter-dropdown state.

## Intuition
The analytics header is the SEO arrival surface feeding the card funnel. Six category glyphs
competed with plain text labels ("Lending", "Staking"…) = visual noise. In the open dropdown,
inactive chips did a CLAUDE.md-**banned** scale-pop on hover, the selected chip was
under-emphasized, and there was no visible "click-away to close" affordance. Less noise +
neumorphic-honest press physics + an unmistakable selected state = a calmer, more trustworthy
arrival surface.

## What changed, in reading order
1. **app.js — Part A (category rail).** In `CATEGORY_TABS.map` (~2804) removed the
   `navIcon(icon)` call so category tabs render label-only. `NAV_ICONS`/`navIcon`/`CATEGORY_TABS.icon`
   kept — the 4 filter pills still render icons.
2. **app.js — Part B3 (scrim element).** Immediately before the top-level global dropdowns
   (~3269) added `activeDropdown && React.createElement('div', {className:'filter-dropdown-scrim',
   'aria-hidden':'true', onClick: () => setActiveDropdown(null)})`. A real, visible click-away
   surface behind the panel.
3. **style.css — Part B1 (no scale-pop).** `.global-filter-dropdown .filter-pill:hover:not(.active)`
   / `.filter-chip…`: `translateY(-2px) scale(1.02)` → `translateY(-1px)` (neuro lift only).
4. **style.css — Part B2 (filled selected).** `.global-filter-dropdown .filter-pill.active,
   .filter-chip.active` → explicit `background: var(--color-primary); color:#fff; semibold;
   translateY(0); shadow raised`. Follow-on `.global-filter-dropdown .chain-pill.active {
   background: var(--chain-color, var(--color-primary)); }` preserves per-chain brand color.
5. **style.css — Part B3 (scrim styles).** New `.filter-dropdown-scrim` — `position:fixed;
   inset:0; z-index:99998` (under the `99999` dropdown), `rgba(0,0,0,0.04)` light /
   `rgba(0,0,0,0.18)` dark, `scrimFade` keyframes, `prefers-reduced-motion` guard. Neuro/low-opacity
   tokens only — no gradient, no glow.
6. **test_nav_rail_ia.js.** Assertion #4 rewritten: category tabs have **zero** `<svg>`, every
   `.google-filter-btn` keeps its `<svg>`. Added an `icons.llamao.fi` 1×1 route so pool-logo loads
   don't mask real page errors. → 10/10.
7. **test_filter_dropdown_polish.js (NEW).** Rendered Playwright driving the real open-dropdown UI:
   scrim present + z-index below dropdown, no scale-pop hover, filled/white selected chip distinct
   from siblings, scrim-click closes both, zero non-ignorable errors. → 5/5.
8. **package.json.** Wired both tests into `npm test`.
9. **Regenerated** `app.compiled.js`, `app.compiled.min.js`, `style.min.css` (`npm run compile` +
   `npm run minify`; byte-identical to fresh build per test_compiled_assets 4/4 + test_minified_assets 9/9).
