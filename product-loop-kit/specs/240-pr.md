# 240 — one footer, one voice (LOW tier explainer)

## Goal
The two surfaces where money decisions happen — the analytics grid (`/?token=`, `/?chain=`) and the
pool-detail page (`/?pool=`) — closed with **"Powered by Defillama API. Made with AI & Degen Love."**
in the footer trust position. "Degen" names the persona the product explicitly does *not* serve
(NORTH_STAR ICP: the cautious retail saver), and the landing page meanwhile closed with a different
voice entirely. UX audit F5, human directive 2026-08-05.

## What changed, in reading order
1. **`translations.js`** — one canonical footer copy set on the ROOT dictionary, EN + KO together:
   `poweredBy` · `defillamaApi` (new) · `footerSignOff` (new — "Education, not advice." / "투자 조언이
   아닙니다.", lifted from the landing trust rail's existing vocabulary, no new claim) · `browseTokens`
   · `browseChains`. `madeWith` and the five `landing.footer*` shadow duplicates are deleted from both
   languages — 12 leaf strings removed, one source of truth left standing.
   The KO `poweredBy` also moves from the terse `"제공:"` to the landing subtree's more natural
   `"데이터 제공:"`, which is the value KO users already saw on `/`.
2. **`app.js:2981` (pool-detail footer) and `app.js:3533` (grid footer)** — both stopped hardcoding
   English literals and now read the same five keys through `t()`. This also fixes a standing CLAUDE.md
   hard-rule violation: those footers rendered English to KO users regardless of `?lang`.
3. **`landing.js:360`** — same markup shape, same five root keys (via a `rootCopy` lookup mirroring the
   existing `plannerCopy` fallback pattern), so all three surfaces compose an identical sentence:
   `Powered by DefiLlama API. Education, not advice.` / `데이터 제공: DefiLlama API. 투자 조언이 아닙니다.`
   **DefiLlama attribution stays** — honest sourcing is a trust rail of the copy, not decoration.
4. **`planner.js:3909`** and **`audit-app.js:967`** — two forced follow-ons, not scope creep: both were
   live consumers of keys this item deletes. `planner.js` re-keys `/plan.html`'s static crawler footer
   hub links after mount (inside a `try/catch` that swallows errors — deleting the keys without this
   would have *silently* stopped KO localization there); `audit-app.js`'s i18n allowlist entry for the
   brand name `DefiLlama API` had to follow the key to root or `test_audit_i18n_parity.js` goes red.
5. **`test_footer_contract.js`** (new, Playwright, port 8877) — drives the real rendered app on all
   three routes × EN/KO and asserts the *population invariant*, not a golden string: the three footers'
   normalized text must be identical (`Set` size 1), each must carry the `api-docs.defillama.com`
   anchor and the `/tokens`+`/chains` hub links, and none may match `/degen/i` or `/디젠/`. One
   source-level leg proves the compiled/minified twins were actually regenerated (item 061's lesson).
   `test_ko_landing_footer.js` keeps its rig and flips its expectations to the new copy.
6. Regenerated committed twins (`node compile-app.js && node minify-assets.js`): `app.compiled*.js`,
   `translations.min.js`, `planner.min.js`. No SEO-estate regen — `tokens/`, `chains/`, `pools/`,
   `stories/` never embedded this footer (grep-zero before and after, zero `<loc>` delta).

## Non-vacuity (the gate was seen to fail)
(a) Reintroducing the retired string turned the render-side degen leg RED in EN only (KO leg correctly
stayed green) *and* the source-level regen leg RED, independently. (b) Dropping the DefiLlama anchor
from the grid footer alone turned the cross-surface-identity leg and the attribution leg RED in both
languages while the hub-link and degen legs stayed green. Both mutations restored byte-identical
(`md5sum` match) and re-regenerated. Full transcript: `specs/240-notes.md`.

## Deviations
`planner.js` and `audit-app.js` (item 4 above) are outside the spec's file list — both are forced by
the key deletion, documented in the notes. `test_footer_hub_links.js`'s prose comments still name the
old key paths; comments only, no assertion touches them, left for whoever cleans that file next.

## Class
Closed for the defect named: 3/3 in-scope surfaces on 5 shared keys × 2 languages, proven at render
time. **Left open, with the number:** the planner's own mounted view has **no** footer sign-off line
at all (`grep 'app-footer' planner.js plan.html` → 0) — if one is ever added it will not inherit this
contract automatically. `stories/` persona pages keep their deliberate voice and were already clean.
