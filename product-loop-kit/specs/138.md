# 138 — Static PROTOCOL_URLS fallback for the "Start Earning" north-star CTA

**Status:** IN_PROGRESS (2026-07-24) · **Risk:** LOW · **Score:** 6.8
**North star:** pool-detail conversion clicks — `pool_click{source=protocol_link}` ("Start Earning on <protocol> ↗") is one of the two.

## Problem (from BACKLOG row 138, rendered repro)
`PROTOCOL_URLS` (app.js) is the static fallback for resolving a pool's protocol URL. The "Start Earning on <protocol> ↗" secondary CTA (PoolDetail.js `.cta-button-protocol`, both hero and repeat_footer placements) renders **only when `getProtocolUrlWithRef(pool)` returns a URL**. Resolution order (`getProtocolUrl`, app.js):

1. `pool.url` — the committed `data/pools-snapshot.json` carries **none** (verified: 0/729 pools have `url`).
2. `dynamicProtocolUrls[...]` — the background `api.llama.fi/protocols` fetch. Fails/races on ad-blockers, outages, slow networks; also blocked entirely in-sandbox.
3. `PROTOCOL_URLS[key]` — the static fallback. **Missing `sky-lending`** (and 34 of the top-50-TVL protocols).
4. `null` → CTA renders nothing.

So whenever the dynamic fetch doesn't land first, the north-star CTA **silently disappears** on the ICP's flagship pool: SUSDS on `sky-lending`, the #3 pool by TVL ($4.7B). In prod the dynamic fetch usually masks it; the gap is graceful degradation of a conversion CTA.

## Fix
Add static `PROTOCOL_URLS` entries for `sky-lending`/`sky` plus the other top-50-TVL protocols that lack one (35 total). URLs sourced from the **live DefiLlama `api.llama.fi/protocols` API** — the same source the dynamic fetch reads — so the static fallback yields the same URL the dynamic path would; affiliate query params (`?ref=`, `?utm_source=`, `?referrer=`) stripped so `getProtocolUrlWithRef` appends `ref=defi.garden` cleanly. Common short-slug aliases added alongside canonical DefiLlama slugs.

No change to `getProtocolUrl`/`getProtocolUrlWithRef` logic, PoolDetail.js, or the trust rails — data-only addition to the fallback map.

## Acceptance (rendered, per 2026-07-11 standing decision — real UI, not fixtures alone)
`test_protocol_cta_fallback.js` (Playwright, snapshot 404'd + `api.llama.fi/protocols` aborted = the degraded condition, no `pool.url`):
1. **Positive** — a real sky-lending SUSDS pool now renders `.cta-button-protocol` purely from the static fallback, and it fires `pool_click{source=protocol_link}` on click.
2. **Negative control** — a pool whose project has no static/dynamic entry renders NO `.cta-button-protocol` (proves the CTA is genuinely URL-gated, so the positive assertion is load-bearing — this is exactly the pre-138 sky-lending behavior).
