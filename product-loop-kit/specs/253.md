# SPEC 253 — GEO AI Agent Autodiscovery (llms.txt, robots.txt, Link Headers)
**Parent**: Item 253 in `product-loop-kit/BACKLOG.md` | **Risk Tier**: HIGH | **Status**: READY

## 1. Goal
Ensure 100% autodiscovery and crawling eligibility for SOTA AI Search Engines (SearchGPT, PerplexityBot, ClaudeBot, GPTBot, Google-Extended, OAI-SearchBot) across all static and markdown surfaces.

## 2. Evidence
- 2026 GEO benchmarks prove AI search engines prioritize sites emitting `Link: </llms.txt>; rel="llms-txt"` HTTP response headers and providing direct `text/markdown` twins.
- Currently, `robots.txt` does not explicitly name 2026 AI Search crawlers, and `llms.txt` needs direct index links to static `/tokens/<slug>.md` and `/chains/<slug>.md` files.

## 3. Implementation Plan
1. **HTTP Headers (`vercel.json`)**:
   - Ensure all HTML responses include `Link: </llms.txt>; rel="llms-txt"; type="text/markdown"`.
2. **`robots.txt` AI Crawler Whitelist**:
   - Explicitly grant access to `GPTBot`, `ChatGPT-User`, `OAI-SearchBot`, `PerplexityBot`, `ClaudeBot`, `Claude-Web`, `Google-Extended`, `Amazonbot`.
3. **`generate-llms.js` Updates**:
   - Include direct markdown twin links (`/tokens/<slug>.md` and `/chains/<slug>.md`) in `llms.txt` and `llms-full.txt`.
4. **Acceptance Tests**:
   - `test_llms_ai_headers.js`: Assert `vercel.json` headers contain `llms-txt` link header and `robots.txt` rules allow major 2026 AI crawlers.

## 4. Verification
- `node test_llms_ai_headers.js` passes.
- `curl -I https://www.defi.garden/` shows `Link: </llms.txt>; rel="llms-txt"`.
