# 253 — PR explainer

**Risk tier: LOW** (copy-only change to `translations.js`, EN + KO together, no new dependency, no trust
rail / router / SEO-surface / config touched — matches NORTH_STAR's LOW fast lane exactly).

## What shipped

A P0 live bug on `main`: commit `6fceca79bb` deleted the `poolNotFoundTitle` translation key from both the
EN and KO namespaces while leaving its only call site (`app.js:3558`, the dead-pool empty-state heading)
unchanged. Since `translations.js`'s `t()` falls back to returning the raw key string when a lookup misses
in both languages, any visitor landing on `/?pool=<id no longer in live data>` — the failure branch of the
`url_direct` leg of the north-star pool-detail surface — saw a heading that literally read
`poolNotFoundTitle` instead of real copy. `npm test` was RED on `main` (`test_dead_pool.js` failing 2/12).

This restores the two deleted strings verbatim from git history (`6f1d624451`, the commit immediately
before the deletion) — no rewording, no new copy decisions.

## How to verify

- `node test_dead_pool.js` → exit 0, 12/12 passing.
- Visit `/?pool=nonexistent-id-xyz` (or `/?pool=nonexistent-id-xyz&lang=ko`) locally — the empty state now
  reads "This pool is no longer tracked" / "더 이상 추적되지 않는 풀입니다" instead of the raw key name.

## Diff

- `translations.js`: 2 lines added (`poolNotFoundTitle` in `en` and `ko`, restored at the position the
  deleting commit removed them from).
- `translations.min.js`: regenerated via `node minify-assets.js` — never hand-edited.
