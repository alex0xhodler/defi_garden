# SPEC 255 — Static Crawl Graph De-Orphaning & Hub-and-Spoke Depth Enforcement
**Parent**: Item 255 in `product-loop-kit/BACKLOG.md` | **Risk Tier**: HIGH | **Status**: READY

## 1. Goal
De-orphan all 2,108 static token and chain pages by enforcing a strict hub-and-spoke crawl graph with a maximum click depth of ≤ 3 from `home.html`.

## 2. Evidence
- Google Search Console API confirmed static pages were "URL is unknown to Google".
- Google 2026 Helpful Content System penalizes programmatic sites whose leaf pages are not connected to crawl hubs or main navigation anchors.

## 3. Implementation Plan
1. **`home.html` Crawler Anchors**:
   - Ensure `home.html` static DOM contains `<footer class="seo-hub-links">` with direct HTML links to `/tokens/` and `/chains/`.
2. **Hub Pages & A–Z Spines**:
   - `/tokens/index.html` lists top 60 tokens by TVL + links to `/tokens/az/a`, `/tokens/az/b`...
   - Every `/tokens/<slug>` page links to its chain hubs (`/chains/<chain-slug>`) and related token pages on the same chain.
   - Every `/chains/<slug>` page links to its top on-chain tokens (`/tokens/<token-slug>`).
3. **Acceptance Tests**:
   - `test_crawl_graph_depth.js`: Assert every generated URL in `sitemap-token-pages.xml` and `sitemap-chain-pages.xml` is reachable in ≤3 clicks from `home.html`.

## 4. Verification
- `node test_crawl_graph_depth.js` passes.
- Execute local crawl graph audit verifying zero orphan pages.
