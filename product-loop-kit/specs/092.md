# 092 — Honest handling of 0%-yield pools in the default browse

Status: IN_PROGRESS (2026-07-14)
Score: 6.5 · Risk: MEDIUM · Prerequisite-pair for 089

## Problem (documented evidence)
Analytics-UX audit (human, 2026-07-14): a screenshot shows collateral assets
(CBBTC / WSTETH / WEETH) rendering a stark **"0%"** and *topping* a TVL-sorted
browse list. These are collateral tokens with no supply yield — huge TVL, zero
APY. A cautious saver reading the yield app sees a broken-looking "0%" at the
very top. This is the prerequisite-pair for 089 (default sort → TVL): flipping
the default to TVL without this fix would surface exactly these 0%-yield pools
at the top of the default grid.

## Rules that bind this (NORTH_STAR / CLAUDE.md)
- **Trust rail — never hide or fabricate a number.** The pool's real APY (0.00%)
  must still render. We add honest CONTEXT, we do not suppress the number.
- Every user-facing string via `translations.js`, EN + natural KO together.
- Reuse existing components/classes; neumorphic tokens only; no gradients/one-offs.
- Money/number formatting stays `en-US` (`formatApy`), never bare toLocaleString.

## Decision — SOTA read (from the audit): DEMOTE + TAG
1. **Demote** 0%/near-0%-yield pools *below* yielding ones in the TVL sort
   (ties broken by TVL desc). This is what 089 needs: TVL-default no longer tops
   with 0% collateral. Applies to the TVL sort in all three browse modes
   (token-first, chain-first, all-pools). Reuses the exact shape of the existing
   `userSortedApy` anomaly-demote (sane-before-anomalous → yielding-before-noyield).
2. **Tag** them honestly: on a no-supply-yield pool card, replace the stark
   "$0.00/day" daily-earnings preview (`.pool-apy-preview`) with an honest tag
   **"No supply yield"** (`.pool-apy-tag`). The `0.00%` hero stays (trust rail —
   number preserved), the tag removes the stark/broken read. We use the generic,
   provably-true "No supply yield" rather than asserting "collateral" (we cannot
   truthfully classify every 0% pool as collateral).

### "near-0" threshold
`NO_SUPPLY_YIELD_EPSILON = 0.01` (%). Total APY `(apyBase||0)+(apyReward||0)`
below 0.01% reads as "0.00%" once `formatApy` rounds to 2 decimals — that's the
exact population the audit screenshot flags. Module-level pure helper
`hasNoSupplyYield(pool)`, reused by both the sort and the render.

### Deliberate scope choices (deviations recorded in notes)
- The demote applies whenever `sortBy === 'tvl'` (there is no `userSortedTvl`
  flag today; TVL becomes the default once 089 ships). A saver sorting by size
  still does not want 0% collateral topping the list — honest default behavior,
  forward-compatible with 089. Not gated on an explicit-click flag.
- Anomalous (APY > `APY_SANITY_LIMIT`) pools are untouched — they are the
  high-APY ⚠ path, disjoint from the 0% population.

## Files
- `app.js`: module-level `NO_SUPPLY_YIELD_EPSILON` + `hasNoSupplyYield`; TVL-sort
  demote in the three sort blocks; `renderPoolCard` tag branch.
- `translations.js`: `noSupplyYield` EN "No supply yield" / KO "공급 이자 없음".
- `style.css`: `.pool-apy-tag` (mirrors `.pool-apy-preview`, calmer/muted — no
  blue accent border; neumorphic tokens only).
- Recompile + reminify: `npm run compile && npm run minify` (analytics app ships
  from `app.compiled.min.js`; source edits are invisible until rebuilt).
- `test_zero_yield_demote.js` (new) wired into `package.json` `test`.

## Acceptance (rendered product behavior — Playwright on the real UI)
Fixture-routed, sandbox-safe (test_list_default.js pattern). Fixture includes a
high-TVL 0%-yield collateral pool plus smaller yielding pools.
1. Under **TVL sort**, the 0%-yield high-TVL pool ranks **below** every yielding
   pool despite its larger TVL (demote works).
2. The 0%-yield pool card renders the **"No supply yield"** tag (`.pool-apy-tag`).
3. Its APY hero still shows the honest **"0.00%"** number (trust rail — nothing
   hidden).
4. Yielding pools do **not** show the tag.
5. Both router paths still render pool cards (`?token=`, `?chain=`) — no regression.
