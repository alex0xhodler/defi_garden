# SPEC 026 — Google Search Console API Engine & Automated Heartbeat Integration
**Parent**: Item 026 in `product-loop-kit/BACKLOG.md` | **Risk Tier**: HIGH | **Status**: SHIPPED

## 1. Goal
Make the loop the owner of Google Search Console (GSC) data for `defi.garden` (`sc-domain:defi.garden`). Enable automated retrieval of clicks, impressions, CTR, average position, indexing coverage, and sitemap status directly during heartbeat runs so all future SEO & GEO decisions are grounded in live Google data.

## 2. Evidence
- Historical organic traffic dropped to 0 because Google's crawler was never updated on new static `/tokens/<slug>` pages.
- Inspection API on `/tokens/usdc` returned: `coverageState: "URL is unknown to Google"`.
- Sitemaps in GSC were last submitted June 4, 2026 (0 indexed URLs).
- 100% of historical Google impressions sit on parameterized URLs (`/?token=...`), which were flagged as duplicate due to homepage canonical tags.

## 3. Implementation
- Built `scripts/gsc_client.js` — zero-dependency RS256 JWT auth + Search Console API v3 / v1 client.
- Authenticated via Service Account JSON key (`~/.hermes/gsc-key.json`).
- Submitted all 5 sitemaps to `sc-domain:defi.garden`:
  1. `sitemap.xml` (index)
  2. `sitemap-token-pages.xml` (825 URLs)
  3. `sitemap-token-pages-ko.xml` (825 URLs)
  4. `sitemap-chain-pages.xml` (70 URLs)
  5. `sitemap-chain-pages-ko.xml` (70 URLs)
- Added `test_gsc_client.js` to `package.json` test chain.
- Ignores key files in `.gitignore` to prevent credential leaks.

## 4. Verification
- Executed `node scripts/gsc_client.js sites` → `siteUrl: "sc-domain:defi.garden"`, `permissionLevel: "siteFullUser"`.
- Executed `node scripts/gsc_client.js audit --site sc-domain:defi.garden` → 1,790 URLs submitted, HTTP 204 success, downloaded by Google.
- Executed `node test_gsc_client.js` → PASS.
