# 091 — Expand the analytics category taxonomy: RWA + Yield Derivatives (HIGH tier)

## Goal
The analytics app classified every pool into just Lending / Staking / LP-DEX / Yield Farming. The human's 2026-07-14 analytics-UX audit asked for three more first-class categories — **Borrowing, RWA, Pendle/yield-derivatives** — so the nav tabs and NL search cover the way people actually think about DeFi. The hard constraint: classification must stay honest (derived from protocol/poolMeta, never fabricated).

## Intuition
A pool's "type" is really its protocol's business model. We already infer it by matching the protocol slug against curated lists (`LENDING_PROTOCOLS`, etc.). Adding a category = adding a curated list + a check + a tab + a parser rule. The only genuinely hard part is **which categories we can label truthfully** from the DefiLlama `/pools` feed.

## The honest-classification call (why only 2 of the 3 shipped)
- **Yield Derivatives** — shippable. `pendle` (160 live pools), `spectra`, `termmax` are unambiguous principal/yield-token & fixed-yield derivative protocols. Protocol-derived → honest.
- **RWA** — shippable. `ondo`, `centrifuge`, `goldfinch`, `openeden`, `midas-rwa`, `usual`, `matrixdock`, `maple`, `clearpool`, etc. are protocol-native tokenized-treasury / on-chain-credit. Protocol-derived → honest.
- **Borrowing** — **deferred, documented.** The `/pools` feed is a *supply-side* dataset: `apy` = what a depositor *earns*. Only 81 of 15,451 live pools (0.5%) mention "borrow" anywhere in `poolMeta`, and a borrow rate is a *cost*, not an earning. A "Borrowing" tab off that sliver, showing a positive APY next to supply yields, would misrepresent both coverage and meaning. There is no supply-vs-borrow distinguisher in the payload. The backlog row explicitly permits "ship only the categories we can classify truthfully" — so Borrowing waits for a real borrow-side data source. (spec 091 §"The honest-classification decision")

## What changed, in reading order (all in `app.js` unless noted)
1. **Two curated protocol lists** (after the existing three, app.js:30-40): `YIELD_DERIVATIVES_PROTOCOLS` and `RWA_PROTOCOLS`, exact slugs derived from a live `/pools` audit.
2. **`CATEGORY_TABS`** module-level array (app.js:~94) — `{ key, labelKey }`, `key:null` = "All". Single source of truth for the tab strip.
3. **`getPoolType`** (app.js:~104): RWA check → Yield-Derivatives check, placed **before** the poolMeta-lending and generic lending/dex/staking checks, so protocol-native classification wins. Returns exactly `'RWA'` / `'Yield Derivatives'`. (Side effect: `maple` now classifies RWA instead of Lending — institutional private credit, more accurate.)
4. **NL parser** (app.js:~338, inside `parseNaturalLanguageQuery`): `/\brwa\b/` or `/real[\s-]world/` → push `'RWA'`; `/\bpendle\b/` or `/yield[\s-]derivativ/` → push `'Yield Derivatives'`. Existing Set-dedupe preserved.
5. **Counts memo** (app.js:1651): added `'RWA':0, 'Yield Derivatives':0` to the initializer (memo is currently unused, but kept correct).
6. **Nav tab render** (app.js:~2704): the four hardcoded `<button>` literals collapse into one `.map()` over `CATEGORY_TABS`, labels via `t(labelKey)`, exact active-state logic and `onClick` preserved, the four filter buttons untouched. Now renders 6 tabs; the strip already `overflow-x:auto`s so extra tabs scroll, never wrap.
7. **`translations.js`** (EN + KO): `navCatAll/Lending/Staking/LpDex/Rwa/YieldDerivatives`. KO: 전체 / 대출 / 스테이킹 / LP/DEX / RWA / 이자 파생상품. This also fixes a latent hard-rule violation (the old tab labels were hardcoded English).
8. **Artifacts**: `app.compiled.js`, `app.compiled.min.js`, `translations.min.js` regenerated via `npm run compile && npm run minify` (home.html loads the min bundles). Never hand-edited.
9. **Test** `test_category_taxonomy.js` (+ appended to the `npm test` chain in package.json): 5 parser-unit assertions (real `parseNaturalLanguageQuery` extracted from app.js) + 4 rendered-Playwright assertions (fixture-routed real chromium: RWA & Yield-Derivatives tabs render, clicking each filters the grid to only its pool, tabs survive a 360px viewport). Per the 2026-07-11 standing decision that UX acceptance = rendered product behavior.

## Deviations from spec
None. All 7 build steps implemented as written; Borrowing deferred per the spec's own decision. (specs/091-notes.md)

## Trust rails
Untouched. No change to `APY_SANITY_LIMIT`, `DEFAULT_MIN_TVL`, anomaly demote/flags, or the degen ⅓ haircut. Classification only reads `pool.project` / `pool.poolMeta` — it never filters, reorders, re-flags, or invents a number.

## Testing / how to verify (human)
- Run `node test_category_taxonomy.js` → 5/5 + 4/4 green.
- Live: open `/?token=USDC` (or `/?chain=Ethereum`) → the nav strip shows **RWA** and **Yield Derivatives** tabs; clicking **RWA** shows Ondo/Midas/etc. pools, **Yield Derivatives** shows Pendle/Spectra pools. Type "pendle" or "rwa" into search → the matching category is selected. Toggle KO → labels become 이자 파생상품 etc.
- `npm test`: the chain halts only at `test_analytics_fires.js`, a pre-existing sandbox-network failure (browser `page.goto` `load`-event timeout on generated `/tokens/` pages) — confirmed to fail identically on a clean origin/main stash-baseline, so not a regression from this diff. Every taxonomy-relevant test passes.

## Measurement
No isolable Mixpanel funnel metric — this is an analytics-app trust/clarity default, same disclosure pattern as 089/092. Proxy: qualitative browse clarity + whether the new categories get selected (the NL parser feeds `search_success` results_count, already instrumented by 020).
