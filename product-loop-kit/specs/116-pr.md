# 116 — PR explainer: re-share the garden from report mode

**Tier: HIGH** (user-facing interactive behavior on the planner render path).
Full walkthrough + quiz below.

## Goal
Close a hole in the viral loop. The share hub only exists at **bloom** (the
moment a plan is first created). But the hook model's payoff — the "Ahead of
plan / On track" **report mode** a returning user sees — had **no way to
share**. That return visit is the highest-intent moment in the loop, and it was
a viral dead end. This adds a one-tap "Share my garden" copy-link CTA there.

## Intuition
Everything needed already shipped:
- `encodePlanToUrl(...)` produces a working link that rebuilds the exact garden
  on open (spec 024/101). Report mode already calls it (for the 115 `.ics`
  reminder), so the link is free.
- `doCopyLink` (bloom) already has a battle-tested clipboard-with-fallback copy.
- `gp-share-textlink` / `gp-report-reminder` / `gp-tend-reminder-note` classes
  already style exactly this kind of control.

So the change is *plumbing an existing link through an existing copy path into an
existing style* — a new share-origination **surface**, not a new mechanic.

## What changed and why (reading order)

### 1. `translations.js` — two new strings, EN + KO together
`reportShareCta` ("🔗 Share my garden") and `reportShareNote` (honest one-liner:
the link rebuilds this exact garden for the recipient). Placed next to the
tend-reminder keys. The "Copied!" success state reuses the existing
`shareLinkCopied` — no new copied key. KO is natural, not machine-literal.

### 2. `planner.js` `GardenReport` — handler (~3381)
```
var reportShareCopiedState = useState(false);       // local copied flag
function reportShareLink() {
  var url = encodePlanToUrl(plan.goal, plan.monthly, plan.years, plan.persona,
                            plan.capital, plan.fundingMode, plan.deadline,
                            plan.poolFilters, plan.mix);   // identical to reportTendReminder
  if (typeof Analytics !== 'undefined') {
    Analytics.trackShareLinkCreated({ method: 'copy', surface: 'report',
                                      goal: plan.goal, persona: plan.persona });
  }
  try { navigator.clipboard.writeText(url).then(setCopied…).catch(textareaFallback…); }
  catch(err) {}
}
```
The arg list is byte-identical to `reportTendReminder`'s `encodePlanToUrl` call,
so the shared link and the calendar-reminder link rebuild the same garden. The
analytics call is guarded (`typeof Analytics !== 'undefined'`) and fires *before*
the async copy, matching `doCopyLink`'s ordering. `surface: 'report'` is the only
new field — it separates report-origin shares from bloom-origin ones in Mixpanel.

### 3. `planner.js` `GardenReport` — render (~3661)
A new `gp-report-reminder` block rendered directly *above* the existing
tend-reminder block: a `gp-share-textlink gp-report-share-link` button showing
`shareLinkCopied` when copied else `reportShareCta`, plus a `gp-tend-reminder-note`
note. **Zero new CSS** — reused classes only (standing decision 2026-07-10).

### 4. `test_report_share.js` (new) + `package.json`
Playwright gate modeled on `test_tend_reminder.js`: seeds a `garden-plan`, routes
a local pools fixture, monkeypatches `navigator.clipboard.writeText` to capture
the copied text. 7 assertions → all 6 acceptance criteria (present+visible; click
copies a `goal=` URL with no yields fetch + shows "Copied!"; EN CTA; KO localized;
dark 360/768/1280 no h-scroll + zero page errors). Appended to the npm `test` chain.

### 5. `planner.min.js` / `translations.min.js`
Regenerated via `node minify-assets.js` (plan.html loads the `.min.js` — 061's
precedent that unminified-only copy ships nowhere). `test_minified_assets.js`
byte-identity assertions confirm the regen.

## Deviations from spec
- Render placement: spec option A (own sibling block above the tend-reminder).
- Used the file-local `useState` alias (= `React.useState`) to match surrounding
  `GardenReport` style. Functionally identical.

## Trust rails / scope
Untouched: `APY_SANITY_LIMIT`, `DEFAULT_MIN_TVL`, anomaly/demotion, degen
haircut, `__APP_MODE` router, canonical/parameterized-URL behavior,
`encodePlanToUrl` output for existing paths. No new deps. No out-of-scope dirs.

## Measurement
`share_link_created { method:'copy', surface:'report', goal, persona }`. 14d
window from the first real report-surface share. Traffic-gated — north star is 0
until the human posts the 069 distribution packs; this ships the mechanism so it
exists when traffic lands.
