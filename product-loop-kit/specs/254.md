# SPEC 254 — GEO/AEO Direct-Answer Openers & Complete Dataset Schema
**Parent**: Item 254 in `product-loop-kit/BACKLOG.md` | **Risk Tier**: HIGH | **Status**: READY

## 1. Goal
Maximize AI citation probability (Perplexity, SearchGPT, Gemini, ChatGPT) by embedding direct-answer openers in the top DOM container and rich `Dataset` + `FinancialProduct` + `ItemList` schemas across all static token and chain pages.

## 2. Evidence
- 2026 GEO research proves AI search engines extract citations from the first 150 words directly below `<h1>` when formatted as concise, factual, numerical answers.
- `Dataset` schema with `dateModified` and `variableMeasured` increases AI engine indexing confidence for financial rate data.

## 3. Implementation Plan
1. **Direct Answer Opener in Generators**:
   - `generate-token-pages.js` & `generate-chain-pages.js`: Render a 2-sentence direct answer container right below `<h1>`.
   - Format: "The top non-anomalous {TOKEN} yield on {CHAIN} is {APY}% APY on {PROTOCOL} (TVL ${TVL}). Data updated {DATE}."
2. **Schema Enrichment**:
   - Embed `Dataset` (`name`, `description`, `dateModified`, `variableMeasured: "Annual Percentage Yield (APY)"`) and `ItemList` schemas in all static token/chain pages.
3. **Acceptance Tests**:
   - `test_geo_direct_answers.js`: Assert top DOM container contains direct answer text and valid `Dataset` JSON-LD schema on 100% of generated static pages.

## 4. Verification
- `node test_geo_direct_answers.js` passes.
- Inspect emitted HTML for `/tokens/usdc.html` using Google Rich Results Test / Schema Validator.
