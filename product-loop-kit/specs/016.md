# Spec 016: Re-brand analytics empty-state buttons to neumorphic tokens

## Evidence
The two analytics empty-state buttons (app.js ~2745-2752, both rendered with `className: 'reset-filters-btn'`) are styled by a pre-neumorphic gradient one-off in style.css (grep `.reset-filters-btn`, currently ~2446-2473): teal/blue `linear-gradient` backgrounds, hardcoded `white` text, glow `rgba(33, 128, 141, …)` shadows stacked onto the raised token. It's the last off-brand survivor of the old design language on this surface, and gradient/off-brand one-offs are a verifier FAIL per the 2026-07-10 standing decision (REUSE COMPONENTS, KEEP DESIGN TIDY).

## Hypothesis
Re-tokening the class in place brings the empty state onto the neumorphic design system with a CSS-only diff — no markup or behavior changes, no new classes, no risk to the analytics render path.

## Change
style.css ONLY — re-token `.reset-filters-btn` and its state rules in place:
1. Base rule: `background: var(--color-surface)`, `color: var(--color-text)`, `border-radius: var(--neuro-radius-md)`, `box-shadow: var(--neuro-shadow-raised)`. Keep all layout properties (margin, display, gap, padding, border, cursor, transition, font-size, font-weight, min-width) unchanged.
2. `:hover` → `box-shadow: var(--neuro-shadow-flat)` + `transform: translateY(-2px)`.
3. `:active` → `box-shadow: var(--neuro-shadow-pressed)` + `transform: translateY(1px)` (press physics — a trust rail).
4. `:focus-visible` → `outline: none` + `box-shadow: var(--focus-ring)`.
5. NO gradients, NO rgba, NO new colors anywhere in the final rules.

OUT of scope: app.js markup, any other class, any new component.

## Acceptance criteria
- [ ] Zero `gradient` and zero `rgba` in the final `.reset-filters-btn` rules (grep-verifiable)
- [ ] Press physics present (`:active` → `var(--neuro-shadow-pressed)` + `translateY(1px)`) and focus ring present (`:focus-visible` → `var(--focus-ring)`)
- [ ] CSS-only diff — no changes outside style.css
- [ ] `node test_planner.js && node test_protocol_parsing.js && node test_qualifier_fix.js` exit 0
