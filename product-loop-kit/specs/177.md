## The trap this spec exists to avoid

`DEFAULT_MIN_TVL` is doing **two jobs**, and only one of them is "the default filter value":

1. `app.js:847` — the initial value of the user-adjustable TVL filter (chips at `:3506` already offer
   `No Min / $10K+ / $100K+ / $1M+ / $10M+`; `?minTvl=` overrides). This is the job the directive is about.
2. `app.js:1141` (`snapshotEligible = !urlParams.pool && urlParams.minTvl >= DEFAULT_MIN_TVL`) and
   `app.js:1167` (`if (poolsSourceRef.current !== 'snapshot' || minTvl >= DEFAULT_MIN_TVL) return;`) —
   the threshold that decides whether the **$10M-floored static snapshot** (`generate-pools-snapshot.js:52`,
   *"$10M floor — applied upstream, never lowered"*) may serve the request, and whether the escape-hatch
   live refetch must fire.

Changing the one constant to `100000` therefore makes BOTH comparisons trivially true at the new default:
the app keeps serving the **$10M** snapshot while the UI claims a **$100K** floor, and the escape hatch
that exists to rescue exactly that mismatch is **disabled by the same edit**. That is a silently false
floor — strictly worse than today's honest $10M. Splitting the two jobs is the whole substance of this item.

## Change

### 1. Split the constant (`app.js`)

- NEW `const SNAPSHOT_MIN_TVL = 10000000;` — the **physical** floor of `data/pools-snapshot.json`,
  mirroring `generate-pools-snapshot.js:52`. Comment must say it mirrors that file and is NOT a
  user-facing default. This is not a new rail; it is the existing snapshot's already-true property,
  named.
- `DEFAULT_MIN_TVL` → `100000` (`$100K`), comment updated to say it is the analytics grid's default
  filter value, human-relaxed 2026-07-29 from $10M.
- Re-key BOTH snapshot guards (`:1141`, `:1167`) to `SNAPSHOT_MIN_TVL`. Nothing else may change about
  their logic.

Consequence, which is the intended trade the human accepted: at the new default the load is
snapshot-INELIGIBLE, so the default grid serves from the live DefiLlama fetch (item 059's ~65KB fast path
is bypassed on the default view). The snapshot still serves any request whose effective `minTvl` is
≥ $10M, and the escape hatch now fires correctly whenever a snapshot-served view drops below $10M.

  Explicitly out of scope (operator flagged to the human before building; not countermanded).
