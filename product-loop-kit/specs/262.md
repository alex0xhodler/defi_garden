# SPEC 262 — Homepage IA Swap & Default Yields/Perps Grid
**Parent**: Item 262 in `product-loop-kit/BACKLOG.md` | **Risk Tier**: HIGH | **Status**: READY

## 1. Goal
Make the Yields & Perps Search Grid the primary default experience on bare `/` (`home.html`), featuring the "Perps & Funding" category tab. Demote "Plant a Garden" (the Planner) to a secondary CTA accessible from individual pool cards/views (`/?pool=<id>`) or `/plan.html`. Strictly preserve the existing `style.css` design system.

## 2. Rationale & Constraints
- **Preserve Current Styling**: Follow existing `style.css` design system tokens, layout structures, and CSS conventions. Do NOT introduce external design frameworks or rewrite CSS tokens.
- **Default Experience Alignment**: On-chain users want instant yield search & perp funding rates upon landing on `/`.
- **Demote Planner**: "Planting a garden" becomes a contextual CTA when viewing a specific pool ("Garden this pool") rather than the homepage kickoff.

## 3. Implementation Plan
1. **Router IA Swap (`home.html`)**:
   - Update `window.__APP_MODE` in `home.html` so bare `/` loads analytics/search grid mode directly (rendering `#root` instead of `#planner-root`).
   - Planner remains accessible at `/plan.html` or when deep-linked with planner state (`?goal=...`).
2. **Front-Page Featured "Perps & Funding" Tab**:
   - Featured "Perps & Funding" category tab displayed on the front-page search grid.
   - Shows top live perp opportunities (Hyperliquid OIL, Lighter SPCX, HYPE, SOL) with market bias and 1-tap referral links (`code=DEFIGARDEN`).
3. **Pool Card "Garden this pool" CTA**:
   - Each pool card / pool-detail view includes the "Garden this pool →" CTA, linking to `/plan.html?pool=<id>` to launch the planner contextually.
4. **Acceptance Tests**:
   - `test_homepage_ia_swap.js`: Assert bare `/` mounts analytics search grid directly, "Perps & Funding" tab is present, and pool cards carry "Garden this pool" CTA.

## 4. Verification
- `node test_homepage_ia_swap.js` passes.
- Verify both bare `/` and parameterized `/?token=USDC` load the search grid smoothly.
