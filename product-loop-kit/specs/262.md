# Spec 262: make OpenAPI describe exactly the live API

Impact: north-star leg A — agent developers receive one truthful machine contract for every route the deployed Worker serves

## Evidence
- `openapi.json` declares `POST /planner`, which `edge/api-core.js` does not serve.
- It omits `/api`, `/health`, `/pools/{id}`, and `/forever-number`: 4 undocumented routes and 1 documented-but-missing route out of 5 routed paths.
- The 2026-08-12 live probe confirmed the Worker is deployed; this is now a false production contract, not dormant groundwork.
- Human decision 2026-08-13: remove `POST /planner`; do not deprecate an endpoint that has no implementation.

## Hypothesis
We believe deriving the OpenAPI path inventory from `edge/api-core.js`'s runtime route table will make agent integrations reliable because additions and removals can no longer drift independently. Confidence: supported.
- Instance of: published machine contract diverging from runtime dispatch.
- Class closed: route-set drift between OpenAPI and the public Worker, guarded both directions.

## Change
- Remove `POST /planner` and its x-payment extension.
- Declare every public route actually dispatched by `edge/api-core.js`, using the public URL forms.
- Describe response schemas from the real handler outputs; do not invent fields.
- Add one both-directions set-equality test between runtime route inventory and OpenAPI operations.
- Keep x402 disabled and do not change pricing, routing, handlers, or deployment configuration.

## Acceptance criteria
- [ ] Every OpenAPI method/path maps to one runtime route; every public runtime route appears in OpenAPI.
- [ ] `POST /planner` is absent from the contract and remains unimplemented.
- [ ] `/api`, `/api/health`, `/api/pools`, `/api/pools/{id}`, `/api/forever-number`, and `/api/pricing` match the runtime inventory after public-prefix normalization.
- [ ] Response schemas validate representative real handler payloads, including error responses and null/optional fields.
- [ ] A runtime-only route mutation and an OpenAPI-only path mutation each make the drift test fail; restore is byte-identical and green.
- [ ] Existing API, MCP, x402-dark, and agent-surface rail tests stay green.

## Instrumentation
No new event. Build leg: contract test. Traffic leg: `agent_reads` API/MCP reads; success remains gated at ≥30 qualified non-loop reads.

## Risk tier
LOW — static contract and test only; no product render path or runtime handler change.

## Open questions
None. The only product choice was answered: remove `POST /planner`.
