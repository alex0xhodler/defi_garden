# 141 — PR explainer (HIGH tier)

## Goal
Remove a **misleading green** from the daily SEO-pipeline CI: a workflow step that claimed to notify search engines about sitemap updates while actually hitting two dead HTTP endpoints and doing nothing.

## Intuition
CI logs are a trust surface for the operator. A step that always prints `✅ Search engines notified` trains the reader to believe a notification happened. When the underlying calls have 404'd/410'd for years, that green is a lie — and it hides the fact that the *real* notification path is a different step (IndexNow). Same failure class as item 078 (a dead sitemap health-count that read as healthy). The honest fix is to delete the dead step, not to "fix" a ping that no provider accepts anymore.

## What changed and why
One file: `.github/workflows/sitemap-update.yml`.

**Removed** the step:
```yaml
- name: Ping Google about sitemap update
  if: steps.verify-changed-files.outputs.changed == 'true'
  run: |
    echo "🔔 Notifying search engines about sitemap update..."
    curl -s "https://www.google.com/ping?sitemap=..." || echo "Google ping failed"   # 404 since 2023
    curl -s "https://www.bing.com/ping?sitemap=..."   || echo "Bing ping failed"     # 410 since 2022
    echo "✅ Search engines notified"                                                 # <- the misleading green
```
**Replaced** with a 6-line comment explaining why it's gone, sitting directly above the **untouched** `Ping IndexNow` step.

Why remove the whole step (not just the Google line the BACKLOG row named): the Bing endpoint in the same step is *also* dead (HTTP 410 Gone), and the `✅ Search engines notified` echo is the actual dishonesty. Removing only Google would leave the misleading green intact. No capability is lost — the very next step, `Ping IndexNow` (`node indexnow-ping.js`), is the live Bing+Yandex notification path (verified HTTP 200 in the same 2026-07-25 log, item 022's proof), and Google's own deprecation notice directs to robots.txt + Search Console, both already in place.

## Diff in reading order
1. `.github/workflows/sitemap-update.yml`, ~line 188: the `- name: Ping Google about sitemap update` step (13 lines incl. trailing blank) is deleted.
2. In its place, a 6-line `# NOTE:` comment documents that the Google/Bing sitemap-ping endpoints were deprecated (2023/2022, return 404/410), that IndexNow supersedes them, and that the dead step was removed under item 141.
3. `- name: Ping IndexNow` and everything after it are byte-unchanged (only shifted up by the smaller replacement).

Net: `1 file changed, 6 insertions(+), 12 deletions(-)`.
