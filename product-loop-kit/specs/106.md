## Territory notes (verified in code 2026-07-15 — these BIND the design)

1. **Where 087's `kpis` reach the planner.** The planner loads pools snapshot-first
   (planner.js:3591-3642): `/data/pools-snapshot-meta.json` behind a 15-min freshness gate, then
   `/data/pools-snapshot.json` — the snapshot CARRIES `kpis` for every pool (verified: 717/717 pools).
   ANY failure/staleness falls through to the LIVE `https://yields.llama.fi/pools` fetch, which has NO
   `kpis`. So: in-app planner runs on fresh snapshots today (kpis present); the note must hide honestly
   when kpis are absent (live fallback / cold CDN). Same null-safe discipline as 088.1's live-landing hide.
2. **Data reality today.** Snapshot `historyPoints` is currently 1–2 (087's CI is still accruing daily).
   So in prod TODAY the note renders only its BUILDING tier (no pool has ≥7 points yet); the STEADY/
   PARTIAL tiers activate automatically as history accrues. The code handles all tiers; data catches up —
   exactly 088.1's precedent (specs/088.md §62-65). All tiers are exercised by the Playwright fixtures.
3. **`curated` is the pool set behind the blended rate.** `var curated` (planner.js:1382) is the
   ≤3 project-deduped, rail-passing pool set; `blendedApy(curated)` (planner.js:649-652) is the median of
   their `poolTotalApy`. The confidence note summarizes exactly this set — no re-selection, no re-rank.
4. **Both archetypes share `heroElement`.** Subscription bloom (planner.js:2784-2796) renders
   `heroElement, planCardElement, subCustomizeElement, …` (NO engineElement); target/growth
   (planner.js:2799+) renders `heroElement,` then plan-strip … `engineElement`. The note must sit right
   after `heroElement` in BOTH trees so it reaches both — engineElement is subscription-absent and
   collapsed-by-default, so it is NOT a viable single home.
5. **Planner `t()` reads the NESTED `planner` block** (planner.js:811 `tr[lang].planner`) and applies
   function values with all args (`v.apply(null, args)`, planner.js:815). New keys go in the `planner:`
   block of BOTH `en` and `ko`, beside `blendedBadge`/`degenHaircutNote` (translations.js ~L290 / ~L899),
   NOT the top-level `rateTrackRecord*` keys (those are PoolDetail's, analytics app).
6. **Minified artifacts.** plan.html loads `planner.min.js` + `translations.min.js` (+ `planner-styles`).
   planner.js is a PLAIN script (no babel compile). After editing planner.js / translations.js /
   planner-styles.css, run `npm run minify` (regenerates `planner.min.js`, `translations.min.js`,
   `planner-styles.min.css`) or `test_minified_assets.js` / `test_css_minified_render.js` fail.

## Acceptance criteria

**A. Confidence helper (module-level, `planner.js`, immediately after `blendedApy` ~L652).**
`function planConfidence(curated)`:
- Returns `null` when `curated` is empty OR no curated pool carries usable kpis (each pool passes only if
  `p.kpis` is a non-null object with `Number(p.kpis.historyPoints) >= 1`). Null → note hides (live path).
- Otherwise returns `{ total, steady, minHp }` computed over the kpis-carrying pools only:
  - `total` = count of kpis-carrying pools.
  - `minHp` = min `historyPoints` across them (the plan is only as tracked as its least-tracked pool —
    the honest floor for any "N days" claim).
  - `steady` = count that clear the 088.1 STEADY test: `hp >= 7 && typeof k.apyStdev === 'number' &&
    k.apyStdev !== null && cur > 0 && (k.apyStdev / cur) <= 0.2`, where `cur = poolTotalApy(p)`.
- Reads ONLY `p.kpis.*` + `poolTotalApy(p)`. NEVER filters, drops, reorders, re-weights, or re-flags a
  pool; never reads/writes the rail constants. Rails untouched.

**B. Render element (`planner.js`, in the bloom component after `curated`/`apy` are in scope).**
`var planConfidenceElement = (function(){ … })();`:
- `conf = planConfidence(curated)`; if `!conf` return `null` (renders nothing).
- Tier STEADY — `conf.steady === conf.total && conf.minHp >= 7`: `t('planConfidenceSteady', conf.minHp)`.
- Tier PARTIAL — else if `conf.steady > 0`: `t('planConfidencePartial', conf.steady, conf.total)`
  (only reachable when `conf.steady < conf.total`, so `total >= 2` → "pools" plural always correct).
- Tier BUILDING — else: `t('planConfidenceBuilding')` (number-free).
- Markup: `e('div', { className: 'gp-plan-confidence gp-animate-in' }, e('span', { className:
  'gp-plan-confidence-icon', 'aria-hidden': 'true' }, '🌱'), e('span', { className:
  'gp-plan-confidence-text' }, copy))`. (`minHp >= 7` in STEADY guarantees the day count is plural.)
- Insert `planConfidenceElement,` immediately AFTER `heroElement,` in BOTH return trees
  (subscription ~L2790, target/growth ~L2806).

**C. Copy (`translations.js`, nested `planner` block, EN + natural KO, both together).** Calm cautious-
saver "education not advice" framing; no hype, no "save up / afford / budget"; numbers only via the args:
- `planConfidenceSteady` (fn `days =>`): EN "This garden is built on pools whose rates have held steady
  across the {days} days we've tracked them — steadier rates make a plan easier to trust."
- `planConfidencePartial` (fn `(n, total) =>`): EN "{n} of the {total} pools behind this plan have a
  steady track record so far; we're still building history for the rest."
- `planConfidenceBuilding` (string): EN "We're still building a track record for the pools behind this
  plan — a longer history makes a blended rate easier to trust."
- KO: natural (not literal) translations of all three, same keys, in the `ko` `planner` block.

**D. Styling (`planner-styles.css`, one new rule, neuro tokens only — model on `.gp-tangibility` L1785).**
`.gp-plan-confidence` calm full-width note: `display:flex; align-items:flex-start; gap:8px;
font-size:0.8rem; color:var(--neuro-text-secondary); margin:0 0 12px; padding:10px 14px;
border-radius:var(--neuro-radius-sm); box-shadow:var(--neuro-shadow-subtle); line-height:1.5;`
plus `.gp-plan-confidence-icon { flex:none; }`. No gradients, no glow, no one-off colors.

**E. Artifacts regenerated in the same commit.** `npm run minify` → `planner.min.js`,
`translations.min.js`, `planner-styles.min.css` regenerated and committed.
