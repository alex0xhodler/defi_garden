# SPEC 256 — Automated GSC Indexing Coverage & Keyword Rank Drift Monitor
**Parent**: Item 256 in `product-loop-kit/BACKLOG.md` | **Risk Tier**: LOW | **Status**: READY

## 1. Goal
Integrate live Google Search Console API reporting (`scripts/gsc_client.js`) into the heartbeat routine (`prompts/heartbeat.md`) to continuously track sitemap indexation percentage, impressions, clicks, CTR, and search keyword rank drift.

## 2. Evidence
- Without automated GSC feedback, the loop previously ran for 3+ weeks building pages that Google had not discovered or indexed.
- Connecting GSC API (`sc-domain:defi.garden`) now provides instant ground truth on Google's actual crawl and indexation state.

## 3. Implementation Plan
1. **Heartbeat Integration (`prompts/heartbeat.md`)**:
   - Step 1 of `heartbeat.md` runs `node scripts/gsc_client.js audit --site sc-domain:defi.garden`.
   - Embed GSC 28d & 7d summary table in every heartbeat report (`reports/YYYY-MM-DD.md`).
2. **Rank Drift Alert**:
   - Alert whenever top search queries drop >3 positions or when sitemap submitted-vs-indexed ratio changes significantly.
3. **Acceptance Tests**:
   - `test_gsc_heartbeat_integration.js`: Assert `scripts/gsc_client.js` executes and formats GSC data into structured markdown for heartbeat reports.

## 4. Verification
- `node test_gsc_client.js` passes.
- Execute heartbeat dry-run verifying GSC data is included in the output report.
