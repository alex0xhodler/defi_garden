## Deviations from spec

- **Test file name / placement (builder's choice, spec allowed).** Chose the standalone `test_css_minified_render.js` (spec offered "new file OR extend an existing rendered test — builder's choice, smallest honest diff"). A standalone file keeps the diff to the two HTML edits + one new file rather than threading CSS-URL assertions into test_hero_copy.js's live-rate logic. Placed after test_minified_assets.js rather than at the end of the chain, because it is the rendered counterpart of that static gate.
- **Chosen computed-style probe: `.gp-tagline { text-align: center }`.** Spec asked for "a computed style that only planner-styles(.min).css provides." `text-align: center` is a literal (not variable-dependent) rule in planner-styles.css:135-138; without the sheet the computed value defaults to `start`/`left`. Picked it over font-size/margin because those resolve through CSS custom properties defined in style.css and are less unambiguous as a planner-sheet-only signal.
- No other deviations. Sources untouched; no critical-CSS inlining; style.css / style.min.css not touched.
