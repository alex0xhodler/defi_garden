# SPEC 257 — Protocol Referral & Affiliate Monetization Integration
**Parent**: Item 257 in `product-loop-kit/BACKLOG.md` | **Risk Tier**: HIGH | **Status**: READY

## 1. Goal
Monetize outbound user clicks ("Garden this pool", protocol deposit CTAs) by mapping protocol-specific affiliate/referral query parameters across top DeFi protocols (Aave, Pendle, Morpho, Aerodrome, Curve, Hyperswap, Fluid, Spark, Convex).

## 2. Evidence
- Users landing on static `/tokens/<slug>` pages or `/pools/<id>` click outbound links to protocols to deposit funds.
- Currently, `getProtocolUrlWithRef` only appends generic `?ref=defi.garden`. Certain protocols require specific keys (`?referral=defi.garden`, `?r=defi.garden`, `?ref=...`) to record integrator fee shares and referral points.

## 3. Implementation Plan
1. **Protocol Referral Dictionary (`app.js` / `generate-protocol-urls.js`)**:
   - Create a single source of truth dictionary mapping protocol keys to their expected referral parameter format:
     - Default: `?ref=defi.garden`
     - Hyperswap: `?ref=defi.garden#/swap?referral=defillama`
     - Pendle / Morpho / Aerodrome / Curve: Protocol-specific referral parameters.
2. **Dynamic URL Resolution**:
   - `getProtocolUrlWithRef(pool)` applies the protocol-specific referral parameter mapping when rendering outbound CTAs.
3. **Acceptance Tests**:
   - `test_protocol_referral_monetization.js`: Assert outbound protocol links for top 10 protocols correctly carry their referral query keys.

## 4. Verification
- `node test_protocol_referral_monetization.js` passes.
- Inspect rendered CTA links on `/tokens/usdc.html` and `/pools/<id>.html` to verify referral query parameters are appended.
