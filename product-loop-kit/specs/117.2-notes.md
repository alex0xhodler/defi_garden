## What shipped
A new "Risk-adjusted" sort option on the analytics grid that ranks pools by the 117 compute leg's
`pool.kpis.apySharpe` (rate-stability Sharpe `(apyMean−4.0)/apyStdev`, null for <8 history points or
sd=0). Graceful no-op until pools accrue ≥8 daily history points (~2026-07-22), then activates —
"land now, lights up as data accrues" (117/117.1 pattern).

- `app.js`: an identical `if (sortBy === 'sharpe')` branch inserted as the FIRST condition in each of
  the three `filtered.sort()` comparators (token-first-inner ~L1823, chain-first ~L1910, token-first
  ~L2010). The existing tvl/apy branches are byte-untouched. The branch:
  1. demotes anomalous pools (`apy > APY_SANITY_LIMIT`) below ALL sane pools — the load-bearing
     trust rail (no anomalous pool jumps the queue via Sharpe);
  2. within the sane group, numeric `kpis.apySharpe` DESC;
  3. null-Sharpe pools sort last (numeric before null);
  4. tie-break TVL DESC (the existing default) → with all-null data (current prod, pre-07-22) the
     grid order is unchanged from the prior default.
- `app.js`: ONE new button in the existing `.sort-control` after the TVL button, reusing
  `view-toggle-btn sort-toggle-btn` (ZERO new CSS), `onClick: setSortBy('sharpe'); setUserSortedApy(false)`,
  label `t('sortByRiskAdjusted')`.
- `translations.js`: `sortByRiskAdjusted` — EN `"Risk-adjusted"`, KO `"위험 조정"` (added together,
  placed next to `rateSharpeNote`).
- Assets regenerated (`node compile-app.js && node minify-assets.js`): `app.compiled.js`,
  `app.compiled.min.js`, `translations.min.js`. Idempotent (second run = no further diff).
  `PoolDetail.compiled.*`, `planner.min.js`, `*.min.css` byte-unchanged (their sources untouched).

## Trust rails
`APY_SANITY_LIMIT`, `DEFAULT_MIN_TVL`, the existing anomaly demotion in the tvl/apy branches, the
degen ⅓ haircut, and the "Powered by Defillama API" attribution are byte-unchanged. The sharpe branch
READS `APY_SANITY_LIMIT` to replicate the same anomalous-below-sane demotion the other sorts apply;
it never changes the constant or the existing logic. Anomaly demotion under sharpe is unconditional
(unlike apy's `!userSortedApy` gate) precisely so a high-Sharpe anomalous pool can never surface above
sane pools — the spec's mandated behavior.
