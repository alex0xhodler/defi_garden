## The bug (rendered repro)

Load any pool in Korean, e.g. `/?pool=<id>&lang=ko`. The pool-detail page shows:

- `이 풀 가든하기 → 5년 후 약 1,189원` — the true figure is **$1,189 USD**. Labeling it `원` (KRW) makes it read as ~₩1,189 (≈ $0.90), a ~1300× understatement.
- `일일 수익 / 1,000원 기준 / $0.10` — a `원`-suffixed value sitting next to a `$`-denominated one in the same card: internally inconsistent.

### Root cause

`translations.js:1348 formatKoreanCurrency(num)` applies Korean 만/억 grouping and a `원` suffix **directly to USD numbers**:

```js
function formatKoreanCurrency(num) {
  if (num >= 100000000) return `${(num/100000000).toFixed(1)}억원`;
  if (num >= 10000) return `${(num/10000).toFixed(1)}만원`;
  return `${Math.round(num).toLocaleString('en-US')}원`;
}
```

Every one of its call sites is fed a USD number that the EN counterpart prefixes with `$`:

| line | KO string | EN counterpart (line) | value fed |
|------|-----------|-----------------------|-----------|
| 756 | `dailyEarningsSubLabel` | `on $X` (75) | `investmentAmount` (USD) |
| 757 | `monthlyEarningsSubLabel` | `on $X` (76) | `investmentAmount` (USD) |
| 787 | `basedOnInvestment` | `Based on $X investment` (106) | `investmentAmount` (USD) |
| 802 | `projectionBody` | `$P … ~$X …` (121) | `principal`, `projectionAmount` (USD) |
| 803 | `gardenThisPoolCtaConcrete` | `Garden this pool → ~$X in Ny` (122) | `projectionAmount` (USD) |

All 5 call sites live in PoolDetail.js (`:506, :563, :598, :692, :1021, :1563`). No FX is ever applied. `formatKoreanCurrency` has **no other callers** (planner included — grepped translations.js / app.js / planner.js; only comments and the module.exports reference it besides these 5).

## The fix (operator recommendation, per BACKLOG row — human may veto)

**Display USD honestly in KO. Do NOT invent an FX conversion** (live FX = a new dependency and a number we can't put through the trust rails — banned by CLAUDE.md and the trust-rail moat).

- Render every affected figure as a `$`-prefixed en-US-grouped USD amount, mirroring the EN counterpart's numeric formatting exactly (plain grouping for investment amounts; `maximumFractionDigits: 0` for projection amounts).
- `$`-for-USD is already the established convention in the KO block (e.g. `최소 TVL $10M 기준` line 771, `$10M 안전 기준` line 774), so this is consistent, not a new pattern.
- Retire the misleading `formatKoreanCurrency` helper (repurpose or delete + fix its export) so no future KO string can re-introduce the same footgun. Keep the module.exports and the `node` test harness loading cleanly.
- Keep Korean sentence structure and particles otherwise unchanged — surgical.

dailyEarningsSubLabel(amount)      → `$<amount en-US> 기준`
