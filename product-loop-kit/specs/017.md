# Spec 017: NL search — every advertised typing-example must actually parse

## Evidence
The search input's typing-animation example queries fail when actually typed (human report from prod). Expected-working classes per the human: bare chains ("solana", "base"), protocol names ("kamino", "curve", "convex"), protocol+category combos ("kamino lenders" → protocol kamino + poolTypes Lending). Advertising queries that return nothing is a broken funnel step, and a bug at a funnel step outranks any experiment at that step (NORTH_STAR experiment discipline).

Structural rot underneath: `parseNaturalLanguageQuery` lives in app.js ~line 129 (call sites ~1272 and ~1849), while test_protocol_parsing.js and test_qualifier_fix.js each test STALE INLINE COPIES of it — the tests can be green while the real parser is broken.

## Hypothesis
Extracting the real parser into a shared module, pinning every advertised example as a hard test fixture, and fixing the parser bugs at root cause will make advertised searches succeed — measurable as search_success vs search_abandonment.

## Change
1. **Extract, verbatim:** move `parseNaturalLanguageQuery` + its helper maps from app.js into a new `search-parser.js` with a UMD guard exactly like canonical.js (`module.exports` for node, `window` global for browser). Loaded via ONE script tag in home.html's analytics-conditional section — NEVER touch the router block or `ANALYTICS_PARAMS`.
2. **Fixtures from the ads:** find the typing-animation example strings (grep app.js/translations.js — the typing-placeholder hook is app.js ~572), list them verbatim in the notes file, and make EVERY one a hard fixture in a new `test_search.js` (test_planner.js assert style) with realistic `allTokens`/`allChains`/`allProtocols` fixture lists.
3. **Fixtures from the human's classes:** bare chains ("solana", "base"), protocol names ("kamino", "curve", "convex"), protocol+category combos ("kamino lenders" → protocol kamino + poolTypes Lending).
4. **Fix at root cause:** parser bugs fixed in the parser (matching order, normalization, protocol map) — no per-string if-hacks. If an example is genuinely unfixable without a rewrite, swap the advertised example for a working one (EN + KO together) and flag it in the notes.
5. **Kill the stale copies:** convert test_protocol_parsing.js and test_qualifier_fix.js to `require('./search-parser.js')` — zero inline copies remain.
6. **Wire the gate:** package.json test chain += `node test_search.js`.

OUT of scope: search UI/UX changes, ranking, router semantics, planner.

## Acceptance criteria
- [ ] All typing-animation example strings pass as fixtures in test_search.js, plus the human's classes (bare chains, protocol names, protocol+category combos)
- [ ] Novel same-class queries parse correctly ("arbitrum", "morpho lending", "aave") — proves root-cause fixes, not per-string hacks
- [ ] search-parser.js is the single source of truth: app.js call sites use it, both old test files require it, zero inline parser copies remain (grep-verifiable)
- [ ] home.html diff is exactly one script tag, in the analytics-conditional section; router block and ANALYTICS_PARAMS byte-identical
- [ ] Full 5-file test chain exits 0: test_planner.js, test_protocol_parsing.js, test_qualifier_fix.js, test_search.js, test_smoke.js
- [ ] Any swapped advertised example updated EN + KO together via translations.js and flagged in notes
