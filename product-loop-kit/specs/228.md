## Change
Smallest version: a pure `handleMcpRequest` (new `edge/mcp-core.js`, same pure-function pattern as
`api-core.js`) implementing MCP streamable-HTTP JSON-RPC on ONE path (`/mcp`) on the SAME Worker:
- `initialize`, `tools/list`, `tools/call`; correct JSON-RPC 2.0 error objects for unknown
  method/tool/params.
- Tools (v0), each a thin wrapper over the EXISTING `api-core.js` handlers — no new data paths, no new
  math: `find_pools` (token/chain/minTvl/limit → railed pools), `get_pool` (id), `forever_number`
  (monthly[, apy]), `explain_rails` (returns the contract's `rails` block + prose).
- Every tool result embeds the same `rails` block the API returns.
- `agent-log-core.js` gains a `path_class` for `/mcp` so D1 counts invocations (leg A).
- README/API.md quickstart: how to add the server to Claude/ChatGPT.
OUT of scope: registry submissions and `.well-known` changes beyond what already exists (human
approval required — NEVER-class org action), the deploy (human, `edge/DEPLOY.md`), auth/payment
(234 territory, pricing stays OFF), prompts/resources/sampling MCP capabilities beyond `tools`,
anything in `telegram-bot/`/`whatsapp-bot/`/`workers/`.

## Acceptance criteria
- [ ] `edge/mcp-core.js` exports a pure `handleMcpRequest` (or equivalent) with NO fetch/env access —
  pools injected, same as `handleApiRequest`.
- [ ] `tools/list` returns every tool with a JSON Schema; the test derives the expected tool set from
  the handler's own registry, not a hardcoded list of 4.
- [ ] Each tool: one happy-path test with railed fixture pools AND one error-path test (bad params →
  JSON-RPC error, not a throw). `find_pools` proves the `DEFAULT_MIN_TVL` clamp: a request with
  `minTvl=0` still returns only pools ≥ the floor, asserted against the imported constant from
  `trust-rails.js` — never a re-typed literal (the 254 mirror lesson).
- [ ] Every `tools/call` result carries the `rails` block; asserted for all tools by iterating the
  registry.
- [ ] Non-`/mcp`, non-`/api` paths keep byte-for-byte pass-through (extend 227's existing test, both
  directions: route set == handled set, the 212 mirror rule).
- [ ] `agent-log-core.js` classifies `/mcp` and `/mcp/*` as a distinct `path_class`; its existing
  classification tests gain the new class and still pass.
- [ ] Tests: the four NORTH_STAR `Test:` legs stay green; new tests run in the plain lane (no browser).
- [ ] Instrumentation: none in Mixpanel (no JS surface); the D1 edge log IS the instrument — state in
  the PR that leg (A) counting starts only at human deploy.
- [ ] Non-vacuity: delete one tool from the registry → tools/list test red AND rails-iteration test
  red; byte-identical restore → green. Recorded in notes with the diff.
- [ ] Population: fixture pools drawn/derived from `data/pools-snapshot.json` shape at test time, not
  a single hand-typed pool.
