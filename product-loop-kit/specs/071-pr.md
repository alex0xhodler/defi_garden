# 071 — Pool-detail rate-volatility honesty note (HIGH-tier explainer)

## Goal
Kill a human-reported trust-killer on the pool-detail page: one pool showed **"TOTAL APY 142.84%"** in the hero and **"30D MEAN APY 405.32%"** in Pool Information — both numbers correct, zero explanation of why they disagree. To the cautious-saver ICP, two wildly different rates on one page reads "scam". Pool-detail is a north-star entry surface (SEO lander → garden_cta → planner → waitlist), and Pool Information is expanded by default, so this pair is visible on every pool with a volatile rate.

## Intuition
The 30d-mean tile's own code comment says it exists to "substantiate whether today's rate is stable or a spike" — but the substantiation was left as an exercise for the reader. The honest fix isn't hiding either number (that would weaken transparency); it's saying out loud, calmly, what the divergence means: reward emissions fluctuate, and the page's projections use the *current* rate, which will move.

## What changed and why (diff in reading order)
1. **`PoolDetail.js`** (+26 lines, the only product-logic change): after the Pool Information stats grid, a conditional `div.rate-volatility-note` renders when `pool.apyMean30d` is a number, both it and the current total APY (`(apyBase||0)+(apyReward||0)`) are > 0, and `max/min ≥ 1.5` (±50% relative divergence — ignores normal wobble, catches the reported 2.8× case; never fires on missing/zero data). Copy interpolates both rates through `_formatApy` (en-US pinned). Styling reuses the sibling tiles' tokens exactly (`--color-background`, `--neuro-radius-sm`, `--neuro-shadow-subtle`, `--color-text-secondary`) — calm and informational, no warning glow or urgency (design-system ban-list).
2. **`translations.js`** (+2 lines): new `rateVolatilityNote(current, mean)` key, EN + natural KO together, same function-key mechanism as `baseApyBreakdown`.
3. **`PoolDetail.compiled.js` / `PoolDetail.compiled.min.js` / `translations.min.js`**: regenerated via `npm run compile` + `npm run minify` — home.html loads only the compiled/minified artifacts, so skipping this would ship nothing (061's caught-bug lesson).
4. **`test_rate_volatility.js`** (new) + **`package.json`** test-chain append: rendered-Playwright acceptance (fixture-routed `/pools`, test_search.js pattern): divergent fixture shows the note with both formatted rates; stable fixture and missing-`apyMean30d` fixture show no note; `?lang=ko` renders Korean; zero page errors on all renders. 5/5 green.
5. **Bookkeeping** (same commit, per the one-commit policy): `specs/071.md`, `specs/071-notes.md`, this file, BACKLOG row, LOG entry.

## Untouched, deliberately
Hero APY, earnings calculator, trust rails (`APY_SANITY_LIMIT`, `DEFAULT_MIN_TVL`, anomaly flags, degen haircut), router/canonical logic, all `?token=/?chain=/?pool=` behavior, analytics calls. `test_smoke.js` still fails in-sandbox — stash-proven pre-existing/environmental (it doesn't stub external hosts; browser HTTPS is proxy-blocked), identical signature with and without this diff.

## Deviations from spec
None functional. Placement chose the spec's primary phrasing (full-width sibling after the grid) over its `gridColumn` alternative; `lineHeight: 1.5` added for prose readability.
