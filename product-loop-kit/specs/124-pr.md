# 124 — PR explainer (LOW tier)

**Goal.** Grow the `protocol_link` half of the pool-detail north-star metric by turning
the "Start Earning on <protocol> ↗" affordance from muted fine-print into a real,
visible secondary CTA — without touching copy or trust rails.

**What changed (reading order).**
1. `PoolDetail.js` — the protocol `<button>`'s `className` goes from `pool-action-protocol-link`
   (a 14px muted text link, `padding: 4px 0`) to `cta-button-protocol` (an existing but
   never-wired raised neuro button). Behavior identical: same `onClick`
   (`Analytics.trackPoolClick(pool, 'protocol_link')` → `window.open(url, '_blank', 'noopener,noreferrer')`),
   same label, same ` ↗`, same "Opens protocol • Wallet required" sublabel.
2. `pool-detail-styles.css` — deleted the two now-orphaned `.pool-action-protocol-link` rules.
   `.cta-button-protocol` (bg `--color-surface`, `--neuro-shadow-raised`, `--neuro-radius-lg`,
   `:hover`/`:active` press physics already defined) is the reuse target — pure neumorphic tokens,
   no new class, no gradient.
3. Regenerated `PoolDetail.compiled.js`, `PoolDetail.compiled.min.js`, `pool-detail-styles.min.css`
   (`compile-app.js` + `minify-assets.js`) — the browser loads the compiled+minified assets.
4. `test_northstar_cta_fires.js` — selector updated to `.cta-button-protocol`.

**Why reuse, not invent.** `.cta-button-protocol` was authored (backlog history) as the pool
detail's secondary-CTA style and left orphaned when the render used the text-link class instead.
Wiring it gives the intended two-tier hierarchy for free: filled-`--color-primary` primary
("Garden this pool") vs raised-`--color-surface` secondary ("Start Earning on <protocol>").

**Trust rails.** Untouched — no APY_SANITY_LIMIT / DEFAULT_MIN_TVL / anomaly-flag / haircut code
in the diff. No copy change → no i18n risk. Focus ring preserved via the global `:focus-visible`.

**Verification.** `test_northstar_cta_fires.js` 7/7 PASS (rendered Playwright, both entry paths).
Compiled/min-asset integrity tests PASS. The 2 pre-existing `test_minified_assets.js` failures
reproduce on `main` (unrelated).

**Measurement.** No new instrumentation — `pool_click{source=protocol_link}` already fires
(PoolDetail.js:517). Expect the `protocol_link` weekly count / CTR to rise once traffic lands;
read via the north-star Mixpanel query in NORTH_STAR.md. Pre-traffic, this is a product-quality
win (a north-star CTA that no longer reads as a footnote).
