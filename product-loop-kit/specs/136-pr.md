# 136 — PR explainer (HIGH-tier gate)

**One line**: Give `.pool-action-card` a mobile `min-width:auto` override so the primary "Garden this pool" CTA and the TOTAL APY value stop being clipped invisible on pool-detail at 360px.

## Goal
Restore the #1 north-star conversion CTA on the entire mobile-width device class. On pool-detail at 360px (light AND dark, reproduced on 2/2 pools), the primary `garden_cta` button and the TOTAL APY value were clipped invisible — only "TOTAL AP" (cut mid-word) plus the secondary protocol button survived. Since `pool_click{source=garden_cta}` is one of the two north-star events, this was a P0 conversion blocker, not cosmetic.

## Intuition
The pool-detail hero is a fixed-width flex row that collapses to a column on mobile. The right-hand action card (`.pool-action-card`) was authored with `min-width: 260px` so it holds its shape in the desktop two-column layout. Nobody added a mobile override for it — so when the row collapses to a ~296px-wide column inside a `padding:32px; overflow:hidden` hero card, the 260px card + its own 20px×2 padding (≥300px) overflows the ~296px it's given, and the ~60px overflow (which contains the right-aligned APY value and the full-width CTA) gets clipped by the hero card's `overflow:hidden`. The sibling `.apy-display-hero` already had exactly this mobile override (`min-width:auto !important`); the action card was simply missed.

## What changed and why (diff in reading order)
1. **`pool-detail-styles.css`** — inside the existing `@media (max-width: 768px)` block, right after the `.apy-display-hero` override, added:
   ```css
   .pool-action-card {
     min-width: auto !important;   /* release the 260px desktop floor on mobile */
     width: 100%;                  /* fill the collapsed column */
     box-sizing: border-box;       /* keep the 20px padding inside that 100% */
   }
   ```
   Reuses the neumorphic idiom already present two rules above; no new tokens, colors, or shadows. One adjacent blank separator line had trailing whitespace normalized — no other rule touched.
2. **`pool-detail-styles.min.css`** — regenerated via `node minify-assets.js`. Production loads the MIN sheet (`home.html:149`, analytics mode), so the raw edit is invisible in prod until the min is regenerated — the exact staleness class item 061 hit. Verifier independently re-minified the current raw and confirmed the committed min is byte-identical.
3. **`test_mobile_cta_clip.js`** (new) — rendered Playwright, fixture-routed (the `test_northstar_cta_fires.js` house pattern: vendored unpkg React/Babel, snapshot 404'd to force the live path, `yields.llama.fi/pools` fulfilled with a real snapshot pool id, `icons.llamao.fi` aborted). Drives `home.html?pool=<id>` and asserts, at **360×780**, that `.cta-button-primary` and `.pool-action-apy .apy-value-hero` are visible and their bounding boxes are fully inside `.pool-hero-card` (±1px) — an element-containment assert, NOT page `scrollWidth` (which passes today and misses this class). A **1280×900** regression guard asserts desktop containment still holds.
4. **`package.json`** — wired `node test_mobile_cta_clip.js` into the `npm test` chain (after `test_northstar_cta_fires.js`) so this P0 regression guard runs automatically. (This was the verifier's one FAIL on attempt 1; fixed.)
