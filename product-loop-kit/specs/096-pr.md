# 096 PR explainer (LOW tier) — environment-gate Mixpanel tracking

**Goal.** Stop dev/test traffic from polluting the north-star funnel. Live evidence (signals/2026-07-14, second Mixpanel pull): the last 2 days of `share_link_opened` were **13/13 from localhost**, `plan_created` **11/11 localhost**; the "80/day plateau" and every prior spike/collapse narrative were mostly `localhost:8792` + Vercel-preview traffic. Real www.defi.garden traffic is a flat ~5–16/day.

**What changed.** One gate at the single choke point every `track*` helper and `startSession()` funnel through — `Analytics.track()` in `analytics.js`:

```js
track(eventName, eventData = {}) {
  if (typeof mixpanel === 'undefined') return;
  if (!this.isProductionHost()) {            // ← new gate
    if (!this._suppressionLogged) { this._suppressionLogged = true; try { console.debug('[analytics] suppressed (non-production host)'); } catch (e) {} }
    return;
  }
  // ...unchanged: enrich + mixpanel.track(...)
}
```

`isProductionHost()` is an exact-match check against `PRODUCTION_HOSTS = ['defi.garden','www.defi.garden','yield.garden','www.yield.garden']`, case-folded, wrapped in try/catch that fails **closed** (suppress) so a bad `location` can never throw funnel-wide.

**Why exact-match, not suffix.** The spec floated "exact or `*.` suffix", but the acceptance list says the allowlist covers *exactly* those 4 hosts. Exact `indexOf` satisfies it verbatim and — unlike suffix logic — can't accidentally match a `defi-garden-*.vercel.app` preview.

**Tests.** `test_analytics_host_gate.js` (16 unit assertions: allowlist exactness, blocked hosts incl. two vercel-preview shapes, `startSession()` inheritance, gate-never-throws) + `test_analytics_host_gate_render.js` (Playwright: real localhost `home.html` load fires **zero** `mixpanel.track` calls, plus a mutation check that neutralising the gate makes `session_start` fire again). Both wired into the npm chain after `test_analytics_fires.js`.

**Scope / safety.** No new event names (this removes noise), no new dependencies, no HTML/loader-snippet changes, trust rails and SEO surface untouched. Only `analytics.js` carries `mixpanel.track` (grep-confirmed single choke point — no page embeds a private copy). `test_analytics_fires.js`'s in-sandbox `page.goto` timeout is pre-existing and diff-independent (stash-baseline reproduced identically).

**Measurement.** Count of events with a non-production `page_url` arriving after deploy · 14-day window (to 2026-07-28) · keep if the count is a structural zero; any non-prod event = the gate leaks → fix/revert.

**Verifier:** PASS, LOW, 6/6 criteria independently re-derived, incl. its own mutation bite-check (forced `isProductionHost→true`, both tests failed, restored clean).
