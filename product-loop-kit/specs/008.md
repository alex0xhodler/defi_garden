# Spec 008: Checkout column CTA hierarchy — one action per intent level

## Evidence
Human prod review (dark-mode screenshot, 2026-07-10, post-005): the checkout column stacks THREE competing CTAs — "Join the waitlist →" (blue, primary), "📸 Share my garden" (button), "🔗 Copy link" (button, equal weight). Two equal-weight share buttons force a choice at the exact moment we want a reflex. Human directive: "tighter, to convert better — remember the north star."

## Hypothesis
We believe collapsing the share card to ONE hero action (📸 Share my garden) with the link demoted to a quiet text link — and tightening the card's copy/spacing — will increase share initiation (north-star step 1) without hurting waitlist clicks, because a single obvious action per intent level (act → spread) removes choice competition. Confidence: supported (basic hierarchy; human-directed).

## Change
Smallest version, share card only:
1. Headline shortened to ONE rendered line at 360px (e.g. EN "Send this garden to someone" — your own better copy welcome; edit/replace the existing `sharePromptHeadline` key value in BOTH en and ko).
2. Primary: "📸 Share my garden" keeps `.gp-share-btn` button styling and its existing handler (doShare, unchanged).
3. Demote the link action: render it as a small text-style link (new class `gp-share-textlink`, NOT `.gp-share-btn`), copy like EN "or copy the link" / natural KO. Keep the existing behavior exactly: native share where `navigator.share` exists, else copy with the existing "✓ Copied!" state; `share_link_created` methods 'native'/'copy' keep firing (handlers unchanged).
4. Tighten: reduce the share card's internal padding/gap one step using EXISTING `--space-*` tokens (e.g. space-16→space-12 class-level change), so the checkout column reads as one decision block.

Do NOT touch: the waitlist button/panel, trust pills, `doShare`/`doCopyLink`/`doNativeShare` logic, analytics.js, arrival banner (007), any router/URL code.

## Acceptance criteria
- [ ] Exactly ONE button-styled share CTA in bloom; the link action is a text link (no `.gp-share-btn` class), keyboard-focusable with a visible focus ring (focus rings are a trust rail)
- [ ] Both demoted-link paths still fire `share_link_created` with methods 'native'/'copy' (trace call sites — handlers must be untouched)
- [ ] Headline is one line at 360px (character-count reasoning documented in notes; EN + natural KO updated together)
- [ ] Spacing changes use existing `--space-*` tokens only; no new colors; no banned effects; reduced-motion untouched
- [ ] `node test_planner.js && node test_protocol_parsing.js && node test_qualifier_fix.js` exit 0 (npm-test smoke runs on the human's machine)
