# Spec 194: the audit calls a by-design-unreachable protocol a defect

Backlog row 194 (score 5.2, READY, promoted 2026-07-31 by item 192's widened measurement run).
No spec file existed; this one is written from documented evidence + measurements taken this run,
and ships in the same PR as the code (2026-07-13 docs-in-first-commit decision).

## 1. The contradiction, stated

Two artifacts from the same day disagree about the same pool:

- `audit-app.js` (2026-07-31 tick): `pool-detail:13392973` (`sdai` / Gnosis, $55.4M TVL) →
  **P1 `degraded-cta`**, *"DefiLlama fallback rendered instead of the protocol CTA
  (.cta-button-protocol) — provenance: project="sdai", disk tiers=[none], this run's
  /data/protocol-urls.json fetch=ok, **kind=defect**"*. P1 ⇒ blocking ⇒ the heartbeat exits non-zero.
- `product-loop-kit/reports/2026-07-31.md:4` closing item 182: *"the one genuinely unreachable pool
  (`sdai`) now renders an honest DefiLlama fallback instead of empty space"* — i.e. **expected,
  deliberately shipped behaviour**.

The backlog row is explicit that this must be **diagnosed, not guessed**: the answer decides whether
this is a one-line classifier change or a reopened 182.

## 2. Diagnosis — measured, not inferred (operator, 2026-07-31, live sources)

**The report is right; the audit is wrong.** `sdai` is a project for which the upstream source
publishes no URL at all, which is precisely the case item 182 built the fallback for.

Evidence, in the order it settles the question:

1. **Upstream has the protocol and has no URL for it.** A live fetch of `https://api.llama.fi/protocols`
   (7,974 protocols this run) contains exactly one match for the key:
   ```json
   { "name": "sDAI", "slug": "sdai", "url": "", "category": "Yield" }
   ```
   The `url` is the **empty string** — not a missing entry, not a stale artifact, not a fetch failure.
2. **The generator is behaving correctly.** `generate-protocol-urls.js`'s `isValidHttpsUrl()`
   (`/^https:\/\/\S/`) deliberately rejects blank/`http://` urls — its own comment says baking those
   *"would ship a dead/insecure link from our own origin forever until the next regen"*. So `sdai`
   correctly gets no baked entry. `data/protocol-urls.json` on this checkout: `urls.sdai === undefined`.
3. **182 shipped the fallback for exactly this case.** `specs/182.md:93` — *"(B) Stop rendering nothing
   — honest fallback for the true-null case (`sdai` and any brand-new protocol)"*; `182.md:51` names
   `sdai` as the one pool unreachable **on the happy path**; `182-notes.md:145` records 735/736 = 99.9%
   with *"single uncovered project = `sdai`"*. The fallback is the deliberate render, not a degradation.
4. **The classifier has no branch that can express this.** `classifyCtaKind()` (`audit-app.js:2179`):
   `!diskDeterminable || bakedRunOutcome==='unknown' → undeterminable`; **`diskTiers.length===0 → defect`**;
   `fetch failed/absent → environment`; else `defect`. A project with **no URL anywhere by design** takes
   the second branch and is called a defect. `CTA_KIND_SEVERITY.defect = 'P1'` ⇒ blocking
   (`blockingFindings()` = P0|P1, `audit-app.js:3552`).
   `test_audit_cta_provenance.js:57` even names that assertion *"the sdai shape"* — the wrong assumption
   is written into the test, which is why it has never been caught by the suite.
5. **The population is small, fully knowable from upstream, and not a stale-artifact problem.**
   Measured live this run against `api.llama.fi/protocols` × `yields.llama.fi/pools` (15,826 pools):

   | population | count |
   |---|---|
   | project keys in the live pools feed with **no** baked URL | **20** |
   | …of those, present upstream with a blank/invalid `url` (**by design unreachable**) | **20** |
   | …of those, **absent** from the upstream protocols feed entirely (would be a real coverage gap) | **0** |

   The 20: `arkonix, atoma, basalt-vault, btcd, canto-lending, cube, gmd-protocol, goose-finance,
   gremlix, guru-network-classic, hydt-protocol, k613, landx-finance, meme-dollar, sdai,
   tender-finance, tizi, tortuga, unblock-equity, uwu-lend`. Serialized sorted: **250 bytes**.

**Verdict: fix the classifier, do NOT reopen 182.** The row's first option is the correct one.

## 3. Change

Give the classifier the third `kind` the row proposes, and give it **positive disk-side evidence** to
base it on — never an inference from absence, which is what the `environment` downgrade's non-vacuity
contract (spec 183) exists to prevent.

**(A) `generate-protocol-urls.js` — record what it deliberately skipped.**
`buildArtifact()` also emits `unreachable`: the sorted list of **population keys whose upstream protocol
entry exists but carries no valid https url** — exactly the keys `buildUrlMapping()` skipped via
`isValidHttpsUrl()`, intersected with `buildPopulation()`. A key absent from the upstream feed entirely
must **NOT** appear here (that is a genuine coverage gap and must keep classifying as a defect).
Keys sorted, so output stays byte-stable across runs (`restrictAndSort()`'s discipline).

> **TRAP — `SCHEMA_VERSION` MUST STAY `1`.** `app.js:1293` hard-rejects the artifact with
> `if (!json || json.schemaVersion !== 1 || …) return;` — bumping to 2 silently drops the whole baked
> tier and regresses north-star CTA coverage **99.9% → 70.9%**. The new field is purely additive;
> every existing reader (`app.js:1297` reads `json.urls` only, `audit-app.js:2118`
> `readBakedProtocolUrls()` reads `parsed.urls`) ignores it. `test_protocol_url_keys.js:136` asserts
> `schemaVersion === 1` and must stay green **unchanged**.

**(B) `audit-app.js` — read it, classify on it, downgrade only on it.**
- `readBakedProtocolUrls()` additionally returns `unreachable: Set|null` — a `Set` when the artifact
  carries a valid string array, **`null` when the field is absent/malformed** (an old artifact must not
  be able to produce a downgrade). Existing `keys` return shape unchanged.
- `classifyCtaKind()` accepts `upstreamUnreachable` (tri-state: `true` / `false` / `null`≡unknown) and
  gains one branch, inside the existing no-tier branch, before it falls through to `defect`:
  ```
  1. !diskDeterminable || bakedRunOutcome === 'unknown'  -> 'undeterminable'   (unchanged)
  2. diskTiers.length === 0 && upstreamUnreachable === true -> 'upstream-null' (NEW)
  3. diskTiers.length === 0                              -> 'defect'           (unchanged)
  4. bakedRunOutcome === 'failed' | 'absent'             -> 'environment'      (unchanged)
  5. otherwise                                           -> 'defect'           (unchanged)
  ```
  Strict `=== true` is load-bearing: `null`/`false`/absent field ⇒ today's `defect`. `upstream-null`
  precedes the `environment` check deliberately — when upstream has no URL to serve, a failed baked
  fetch changes nothing about what the page *should* render, so the by-design reading is still correct.
- `CTA_KIND_SEVERITY['upstream-null'] = 'P2'` (non-blocking, same lane as `environment`).
  `ctaFindingSeverity()` is **not** touched: a `missing` shape stays P1 for every kind including this
  one — 182's `renderProtocolCtaBlock()` always renders one of the two buttons, so an absent element is
  never explained by URL provenance (spec 183 verifier round 3).
- The pool driver (`audit-app.js:~3054`) resolves `upstreamUnreachable` for the current `project` using
  the **same two key shapes** `projectHasUrl()` uses (slugified + raw), and appends a by-design clause to
  `detail`, mirroring `environment`'s reconciliation wording so both downgrades read the same way:
  `— by design: the upstream protocols feed publishes no site URL for this project (blank \`url\`), so
  182's honest DefiLlama fallback IS the intended render; downgraded to non-blocking.`

**(C) `data/protocol-urls.json` — regenerate** (`node generate-protocol-urls.js`; live fetch works
in-sandbox per the 2026-07-12 network decision). Expect `urls` unchanged modulo the day's churn, plus
the new `unreachable` array (~20 keys / ~250 B).

**Out of scope (do not touch):** `PoolDetail.js`, `app.js`, `translations.js`, `PROTOCOL_URLS`, any
trust rail, the `__APP_MODE` router, any parameterized URL, any SEO artifact. No new dependency.
No user-facing string ⇒ EN+KO is vacuously satisfied (state this, don't leave it unsaid).

## 4. Acceptance criteria

Pure-function criteria extend `test_audit_cta_provenance.js`; the rendered criteria go in a new test
registered in `package.json`'s `test:serial` (an unregistered test never runs — 193's finding; pick
ports grep-confirmed unclaimed across `test_*.js`).

1. **New kind.** `classifyCtaKind({diskDeterminable:true, diskTiers:[], bakedRunOutcome:'ok',
   upstreamUnreachable:true})` → `'upstream-null'`; same with `bakedRunOutcome:'failed'` and `'absent'`
   → `'upstream-null'` (branch order proof).
2. **The downgrade is not the default.** Same inputs with `upstreamUnreachable:false` → `'defect'`;
   with `upstreamUnreachable:null` → `'defect'`; with the argument **omitted entirely** → `'defect'`.
3. **The four pre-existing kinds are unchanged.** Every existing assertion in
   `test_audit_cta_provenance.js` still passes; the one at `:57` may be re-worded (it currently claims
   *"the sdai shape"* → defect, which this item disproves) but must keep asserting `defect` for the
   no-tier / not-upstream-unreachable case.
4. **Shape beats kind.** `ctaFindingSeverity('fallback','upstream-null')` → `'P2'`;
   `ctaFindingSeverity('missing','upstream-null')` → **`'P1'`** (the 183 round-3 asymmetry survives).
5. **Generator, over fixtures (no network).** With a protocols fixture containing a valid-url protocol,
   a blank-url protocol, and a pools fixture whose projects cover both plus one project absent from the
   protocols feed: the blank-url key **is** in `unreachable`; the valid-url key **is not**; the
   upstream-absent key **is not**.
6. **The artifact still loads.** The regenerated `data/protocol-urls.json` satisfies `app.js:1293`'s
   exact guard (`schemaVersion === 1 && typeof urls === 'object' && !Array.isArray(urls)`) and
   `test_protocol_url_keys.js` stays green **without edits**.
7. **RENDERED — the false P1 is gone.** A real-Chromium `runAudit()` over the real sdai pool
   (`13392973-be6e-4b2f-bce9-4f7dd53d1c3a`, via `buildPoolSurfaces`' **bare comma-string** `poolIds`
   contract — the array form throws `overrideRaw.split is not a function`, 193's lesson) produces a
   `degraded-cta` finding for it whose severity is **P2** and whose detail contains
   `kind=upstream-null`, and `blockingFindings()` over that run contains **no** finding for that pool.
8. **RENDERED — it still fires for a real gap (non-vacuity).** The same rendered path, with the
   unreachable evidence withheld (e.g. an injected/overridden artifact lacking the project), yields the
   **P1 `defect`** finding back. A run in which every `degraded-cta` is downgraded is the failure this
   criterion exists to prevent.

Timebox: 5 foreground minutes per test invocation. The full ~100-file suite is not required — state
what was run and what was not.
