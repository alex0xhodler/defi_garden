# Spec 001: Wire Mixpanel MCP into the repo so loops read live signals

## Evidence
Heartbeat has no analytics access at runtime: no `.mcp.json`, no Mixpanel credentials anywhere in the repo. The installer had to pull the baseline manually on 2026-07-09 (see `signals/2026-07-09.md`): session_start 132, plan_created 5, share_link_* 0 over 30 days; north-star funnel 0 → 0. Until this ships, every heartbeat runs signal-degraded.

## Hypothesis
We believe a project-scoped Mixpanel MCP config lets scheduled `claude -p` heartbeats query project defigarden (4042048) directly. Confidence: supported — the same Mixpanel MCP already answers queries for this project in Cowork.

## Change
Add `.mcp.json` at the repo root configuring the Mixpanel MCP (official remote server preferred; API-key/service-account variant only if remote is unusable), plus a one-time-auth note for the human. OUT of scope: dashboards, query helper libraries, any product code, committing any credential or token to the repo (hard ban — keys live in env/keychain only).
