# 138 — PR explainer (LOW tier)

## Goal
Keep the "Start Earning on <protocol> ↗" CTA — one of the two north-star pool-detail conversion clicks (`pool_click{source=protocol_link}`) — from silently disappearing when the dynamic protocol-URL fetch fails.

## Intuition
The CTA only renders when a protocol URL resolves. Resolution is: `pool.url` → dynamic `api.llama.fi/protocols` map → static `PROTOCOL_URLS` → null. The snapshot has no `pool.url`, and the static map was missing `sky-lending` (and 34 other top-50-TVL protocols). So on any load where the background fetch failed/raced (ad-blocker, outage, slow net), the CTA vanished on the ICP's flagship $4.7B SUSDS pool. This adds the missing static fallbacks so the CTA degrades gracefully.

## What changed (reading order)
1. **app.js — `PROTOCOL_URLS`**: +35 top-50-TVL protocol entries (50 keys incl. aliases), `sky-lending`/`sky` first. URLs pulled from the live DefiLlama `/protocols` API (the same source the dynamic path uses), affiliate query params stripped.
2. **app.compiled.js / app.compiled.min.js**: regenerated (`npm run compile && npm run minify`) — production serves the `.min`, so the source edit alone wouldn't ship.
3. **test_protocol_cta_fallback.js** (new): rendered Playwright acceptance — sky-lending CTA renders + fires from the static fallback under the degraded condition; negative-control pool renders no CTA.
4. **package.json**: wired the new test into `npm test`.

## Why it's LOW risk
Data-only addition to a fallback map. No change to resolution logic, PoolDetail.js, the `__APP_MODE` router, parameterized-URL behavior, or any trust rail (`APY_SANITY_LIMIT`, `DEFAULT_MIN_TVL`, anomaly flags, degen haircut). No new package.json deps. Diff well under 150 lines of hand-written source.

## Deviations
Deferred the "bake url into the snapshot" durable option (ties to 134 study). See 138-notes.md.

## Measurement
No new instrumentation needed — both north-star CTAs already fire `pool_click{source=...}`. Expected effect: fewer pool-detail renders where the protocol CTA is absent → higher `protocol_link` click availability, especially on ad-blocked / slow-network sessions and top-TVL RWA/lending pools that previously had no static fallback.
