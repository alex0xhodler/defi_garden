# 128 — Dedup the pool-detail earnings numbers

**Status:** SHIPPED · **Risk:** LOW · **Score:** 6.0
**North star:** pool-detail conversion clicks (`pool_click{source∈garden_cta,protocol_link}`) — this is a decluttering fix on that exact surface.

## Problem (from BACKLOG row 128, P2, screenshot evidence)
The daily / monthly earnings figure rendered THREE times on the pool-detail page:
1. **Top "Quick Metrics" stat cards** — a "Daily earnings" card (`$0.10`) + a "Monthly earnings" card (`$3`) (`PoolDetail.js` ~L543–611).
2. **The yield calculator's expandable result** — 1 Day / 7 Days / 30 Days tabs (`PoolDetail.js` ~L900–1020).
3. **A redundant numeric subhead on the calculator header** — `"Quick estimate for $1,000: $0.1/day"` (`PoolDetail.js` L750, translation key `quickEstimate`).

The same number appearing 3× lengthens the page and dilutes the conversion CTAs ("Garden this pool" / "Start Earning on <protocol>"), which is the whole point of the page post-2026-07-23 north-star pivot.

## Decision — consolidate to ONE earnings surface + the calculator
- **Keep** the top stat cards as the single at-a-glance earnings surface (Daily + Monthly, prominent, above the calculator).
- **Keep** the calculator as the interactive earnings tool (its result shows only when expanded — not a passive duplicate).
- **Remove** the redundant numeric `"Quick estimate … $0.1/day"` subhead — surface #3, the pure duplicate. Replace it with a non-numeric invite line so the collapsed calculator header keeps a helpful affordance without repeating the figure.

Rationale for keeping the stat cards (not the subhead) as the survivor: the stat cards are the more prominent, always-visible glance that sits with the CTA cluster; the subhead only existed as a collapsed-state preview of a number already shown right above it.

## Changes
- `PoolDetail.js` L750 — swap the `t('quickEstimate', …)` numeric subhead for `t('calcSubPrompt')` (no params, non-numeric).
- `translations.js` — replace the `quickEstimate` key (EN + KO) with `calcSubPrompt` (EN: "See your daily, weekly & monthly returns"; KO: "일간·주간·월간 수익을 확인하세요"). `quickEstimate` had exactly one call site (grep-verified), so it is removed, not orphaned.
- Regenerated committed outputs: `PoolDetail.compiled.js`, `PoolDetail.compiled.min.js`, `translations.min.js` (via `npm run compile && npm run minify`).
- `test_earnings_dedup.js` — new rendered-Playwright acceptance test.

## Acceptance criteria (rendered product behavior — 2026-07-11 standing decision)
`test_earnings_dedup.js`, driving the real pool-detail UI (`/?pool=<lido id>`, fixture-routed like `test_northstar_cta_fires.js`), asserts:

4. No unexpected page/console errors.
