# Spec 265: MCP discovery cards advertise a dead URL, wrong transport and phantom capabilities — on a now-LIVE server

Impact: north-star leg A — every agent that trusts the advertised discovery card fails to reach the live MCP server (live-probed: card says `sse` at `/api/mcp` → 404; real server is Streamable HTTP at `/mcp` → serving)

## Evidence
- 2026-08-12 heartbeat, live probes (signals/2026-08-12.md): the human deployed the edge Worker —
  `/api/health` 200, `/mcp` answers JSON-RPC `initialize` + `tools/list` + `tools/call` correctly.
- Same tick: `GET /api/mcp` → **404**, `POST /api/mcp` (JSON-RPC initialize) → **404** (api-core's
  unknown-route body). The advertised endpoint does not exist; the 265 filing's "must land at or
  before deploy" boundary has been crossed — the cards now lie about a LIVE server.
- THREE byte-identical cards (md5 `82f8aeab3994f0f21fc49e02940ed3cd`, enumerated by 228's verifier):
  `.well-known/mcp.json`, `.well-known/mcp/server-card.json`, `.well-known/mcp/server-cards.json` —
  each declares `"url": "https://www.defi.garden/api/mcp"` + `"type": "sse"` + a `prompts`
  capability the server does not implement (live `initialize` returns `capabilities: {tools: {}}`).
- `vercel.json:171` broadcasts `Link: </.well-known/mcp/server-card.json>; rel="mcp-server-card"` on
  EVERY response (live-verified 2026-08-12 on `/`), so the wrong pointer reaches every consumer.
- Two further hardcoded `/api/mcp` artifacts named by 228's round-3 verifier:
  `validate_readiness.py:62`, `dns-aid-zone.txt:14`.

## Hypothesis
We believe correcting the cards to the real endpoint (`https://www.defi.garden/mcp`), real transport
(Streamable HTTP), and real capability set (`tools` only) will remove a hard 404 from the agent
install path, because the cards are the discovery mechanism the Link header points every response at.
Confidence: supported (the 404 and the working `/mcp` are both live-probed, not inferred).
- Instance of: published-claim-without-an-implementation (same class as 261/262 — a machine-readable
  agent artifact stating something the code does not serve).
- Class closed by this item: no — `openapi.json` path drift is 262 (BLOCKED on the human);
  free/paid prose drift is 267. This item closes the MCP-discovery members only (5 artifacts).

## Change
Smallest version: edit the 3 cards to `{url: https://www.defi.garden/mcp, type: streamable-http}`
(exact type string per the current MCP server-card schema — builder verifies against the schema the
cards' `$schema` declares), capabilities `tools: {list, call}` only, drop `prompts`; fix
`validate_readiness.py:62` + `dns-aid-zone.txt:14`; keep `vercel.json`'s Link header (target file
now truthful). Add a parity test: card URL/transport/capabilities ↔ the live server's own
`initialize`/`tools/list` handlers in `edge/mcp-core.js` (derive expected values from mcp-core,
never hand-type them — the 212 mirror rule). OUT of scope: registry listings (human-owned),
llms.txt advertising (item 277), openapi.json (262).
