# 115 — PR explainer (HIGH tier): the honest `.ics` tend reminder

## Goal
Build the **trigger** leg of the documented hook model. `CLAUDE.md`'s loop is trigger → action → variable reward → investment. A browser + code audit this week (`reports/2026-07-15-hook-model-discovery.md`) found action, variable reward, and investment all built — but **no trigger at all**. The "you're ahead of plan" reward in report mode is only ever seen if the user *spontaneously* comes back. A loop with no trigger cannot retain. Item 115 adds the missing trigger without a backend, a permission prompt, or a dark pattern.

## Intuition
A static, no-backend site can't push or email. But it *can* hand the user a file their own calendar will remind them from: an `.ics` event with `RRULE:FREQ=MONTHLY`. The event's `URL`/`DESCRIPTION` is the plan's own share link, so tapping the reminder a month later deep-links straight back into the exact garden (report mode auto-loads). The trigger is honest and self-service: the user installs it into their own calendar; we never contact them.

## What changed, in reading order

**1. `planner.js` — the `.ics` engine (after `encodePlanToUrl`, ~L970).**
- `buildTendReminderIcs(shareUrl, summary, description)` returns RFC5545 text: `BEGIN:VCALENDAR … BEGIN:VEVENT`, `DTSTART` ~30 days out formatted in ICS UTC basic form (`YYYYMMDDTHHMMSSZ` from `getUTC*` — no locale, satisfies the house "never bare `toLocaleString`" rule), `RRULE:FREQ=MONTHLY`, and `SUMMARY`/`DESCRIPTION`/`URL` with commas/semicolons/newlines escaped. `DESCRIPTION` and `URL` both carry `shareUrl`.
- `downloadTendReminder(...)` wraps the text in a `Blob({type:'text/calendar'})`, creates an object URL, clicks a synthetic `<a download="defi-garden-tending.ics">`, and revokes the URL. No dependency, no Notifications API.

**2. `planner.js` — bloom surface (~L2880, inside `sharePromptElement`).**
`doTendReminder()` builds the URL with the SAME `encodePlanToUrl(goal, monthly, years, persona, props.capital, props.fundingMode, props.deadline, poolFilters, selectedSubs)` call the share buttons already use, downloads the `.ics`, and fires `Analytics.trackTendReminderAdded({surface:'bloom', …})`. Rendered as a `gp-share-textlink gp-tend-reminder` button + a calm `gp-tend-reminder-note` caption, appended as the last children of the existing share prompt.

**3. `planner.js` — report mode (~L3370, in `GardenReport`).**
`reportTendReminder()` rebuilds the URL from the saved `plan` fields (`plan.goal/monthly/years/persona/capital/fundingMode/deadline/poolFilters/mix`) and fires `surface:'report'`. Rendered in a `.gp-report-reminder` block after the existing `gp-report-actions` row, so a returning user can re-arm the reminder.

**4. `translations.js` — EN + KO together.** `tendReminderCta`, `tendReminderNote` ("We'll never email you — this adds a private monthly reminder to your own calendar."), `tendReminderTitle`, `tendReminderDesc`, in both `en` and `ko` blocks with natural Korean.

**5. `analytics.js`.** `trackTendReminderAdded({surface, goal, persona})` → `tend_reminder_added`, matching the existing `track*` shape.

**6. `planner-styles.css`.** `.gp-tend-reminder-note` (12px muted caption via `--color-text-muted`) and `.gp-report-reminder` (centered column). Existing tokens only; `:active` sink inherited from `gp-share-textlink`.

**7. `*.min.js` / `*.min.css`.** Regenerated via the repo's `node minify-assets.js` because `plan.html` serves the minified bundles.

**8. `test_tend_reminder.js` + `package.json`.** New Playwright gate (house harness) wired into `npm test`; seeds `garden-plan` → report mode, captures the `.ics`, asserts VEVENT/RRULE/DTSTART/URL, EN+KO, bloom-surface control, dark responsive.

## Deviations from spec
- **Line folding** of long `DESCRIPTION`/`URL` values (RFC5545 >75 octets) is not implemented; mainstream calendar clients parse unfolded lines fine. Candidate follow-up only if a client rejects it.
- Minified-asset regeneration (pipeline requirement, not scope creep) and the pre-existing environmental `test_analytics_fires.js` note — see `115-notes.md`.

## Risk tier: HIGH
New user-facing capability beyond copy/styling — HIGH by policy. But no new dependency, no permission prompt, no trust-rail/router/SEO/bots surface touched; reads derived plan fields only. Auto-mergeable after verifier PASS + tests green.
