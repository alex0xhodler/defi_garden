# Spec 011: Stop the canonical lie — per-mode canonical/title truth from the first byte JS runs

## Evidence
Raw fetch of any parameterized URL (e.g. `?token=ALEPH`, 2026-07-10) returns static `canonical → https://www.defi.garden/`, planner title, planner description (home.html:8/15). GSC: 1,955 "Alternate page with proper canonical" (Google believed the wrong canonical) + 521 "Duplicate, Google chose different canonical" (static vs JS-rewritten canonical conflict). Full chain: specs/010-diagnosis.md.

## Hypothesis
We believe removing the static (wrong) canonical and having the IA router authoritatively set canonical/title/og:url for BOTH modes on every load will collapse the canonical-confusion classes and unblock indexing recovery, because a missing pre-render canonical is neutral while a wrong one is actively harmful, and rendered crawls will then see one consistent self-referencing signal per URL. Confidence: supported (mechanism observed directly).

## Change
home.html only:
1. Remove the static `<link rel="canonical" href="https://www.defi.garden/">` from the head (home.html:15). Keep the `<link>` ELEMENT strategy: the router script creates/updates it.
2. In the IA router (~54-80), ALWAYS set canonical: analytics mode → `https://www.defi.garden/` + a NORMALIZED query (only the params that define the page: token, chain, pool, poolTypes, protocols, minTvl, minApy — in a stable order; drop `lang` and any unknown params so ko/en variants self-canonicalize to one URL); planner mode → `https://www.defi.garden/` exactly.
3. og:url follows the same value in both modes; analytics title/description rewrite stays as is (verify it still runs after the head change).
4. plan.html: verify its canonical is correct/self-referencing while you're in territory — fix ONLY if it points at the wrong URL; note findings either way.

OUT of scope: sitemaps, app.js, any URL semantics, prerendering, robots meta (that's 012).

## Acceptance criteria
- [ ] Raw served HTML of a parameterized URL contains NO canonical tag pre-JS (grep the file; static hosting = same file for all URLs)
- [ ] With JS: `?token=USDC` → canonical + og:url `https://www.defi.garden/?token=USDC`; `?token=USDC&lang=ko` → same canonical (lang stripped); `?token=USDC&chain=Base` → stable param order; bare `/` and `/?fresh=1` → `https://www.defi.garden/`; a planner share URL (`?goal=...&pace=...`) → root canonical (planner mode)
- [ ] Verification method: since Playwright isn't runnable in this sandbox, write the canonical-computation as a small pure function in the router script and ALSO assert it via a node-runnable test file (test_canonical.js, following test_planner.js's pattern — the function must be factored so node can require/execute it standalone); wire it into the `npm test` chain in package.json
- [ ] `node test_planner.js && node test_protocol_parsing.js && node test_qualifier_fix.js && node test_canonical.js` exit 0
- [ ] Both router paths still render (no behavioral change to __APP_MODE decisions — do not touch ANALYTICS_PARAMS)
