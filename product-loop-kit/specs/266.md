# Spec 266: the WebMCP surface re-implements both trust rails as hardcoded literals — third copy, unguarded

Impact: guardrail — trust rails (`APY_SANITY_LIMIT`, `DEFAULT_MIN_TVL`): a live MCP-branded surface applies its own hand-typed copies that silently diverge the day the rails move

## Evidence
- `home.html:227-343` registers WebMCP tools (`window.navigator.modelContext.provideContext`) on
  every `/` and `plan.html` load — live today, reachable by any browser-hosted agent.
- `home.html:269-270`: `if (p.tvlUsd < 100000) return false; if (p.apy > 1000) return false;` —
  hand-typed literals, a THIRD copy of `trust-rails.js` values (after the prose class 261 closed and
  the machine-readable class 254 closed). Correct today by coincidence only.
- Worse than drift: `p.apy` is DefiLlama's base-apy field, NOT the `apyBase + apyReward` total every
  railed surface computes — so the sanity limit is applied to the WRONG NUMBER today, not just a
  copy that could go stale. A pool with apyBase 900% + apyReward 900% passes this filter.
- The irony, load-bearing: ~20 lines above (`home.html:246-249`) a comment explains why a
  neighbouring description string must derive from the rails.
- Filed by item 228's build (2026-08-11); item 261's rail-claims test scans agent-facing FILES, and
  `home.html` inline JS is outside its population — nothing guards this site.

## Hypothesis
We believe deriving the WebMCP filter from `trust-rails.js` values (baked at build/regen time or
read from the same constants the compiled app uses) and computing `apyBase + apyReward` will make
the surface rail-correct permanently, because it removes the only remaining hand-typed rail copy.
Confidence: supported (the divergence mechanism is the exact class 254/261 measured twice).
- Instance of: hand-maintained mirror of a defining constant (playbooks/mode-enumeration-staleness.md
  mirror rule; RAZOR example 5).
- Class closed by this item: mostly — after this, `grep -rn "100000\|> 1000"` on agent-reachable
  surfaces should return only `trust-rails.js` derivations; the builder re-counts and names any
  residue with a number.

## Change
Smallest version: `home.html`'s WebMCP `search_yield_pools` filter (a) computes
`totalApy = (p.apyBase||0) + (p.apyReward||0)` and tests THAT against the sanity limit, (b) sources
both thresholds from `trust-rails.js` (home.html is static — inject at the existing compile/regen
step the way the description string comment says, or inline `<script src>` the rails module if the
loader order allows; builder picks the mechanism that survives the daily cron regen), and (c) a
test asserting the rendered home.html carries no bare rail literal and that the WebMCP filter
excludes a fixture pool with apyBase+apyReward > limit. OUT of scope: the WebMCP discovery-card
claims (265), removing WebMCP (human product call — it's a live surface).
