## Territory notes (verified in code 2026-07-15 — these BIND the design)

1. **`kpis.tvlTrend` semantics (compute-kpis.js:100-102).** Signed fraction of the TVL
   change from the earliest to the latest retained point: `(last.tvlUsd − first.tvlUsd) /
   first.tvlUsd`, `round(…, 4)`. So `0.25` = +25% (grown), `-0.30` = −30% (shrunk).
   `null` when the pool has `< 2` history points OR the earliest `tvlUsd` is `0` (division
   guard). NEVER `Infinity`/`NaN` — the guard is upstream.
2. **How `kpis` reach `PoolDetail` (unchanged from 088.1).** `PoolDetail` takes `pool` as
   a prop and never fetches. In-app browse→detail carries `kpis` (the snapshot carries
   them). A direct `?pool=<id>` deep link loads LIVE `/pools`, which has NO `kpis` → the
   note must hide honestly. Live SEO landings therefore show nothing; correct.
3. **Data reality today.** With few retained points most pools have `tvlTrend: null` or a
   tiny value; the note only renders once history accrues a meaningful (`|tvlTrend| ≥ 0.25`)
   move over a `≥ 7`-point window. The code handles it; the data catches up (088.1
   precedent).
4. **Sibling notes already stack.** `PoolDetail.js` renders, in order: 071 volatility note
   (~1297), 088.1 track-record note (~1326), 103 momentum note (~1377). The momentum note
   already co-renders with track-record. This note is a NEW distinct axis (deposit-base
   direction, not APY) and slots in immediately AFTER the momentum note, following the same
   `!(071-boolean) && kpis-gate` shape.
5. **Yields to 071 (consistency).** Every honesty note yields entirely to the 071
   volatility note (same divergence boolean) so a volatile pool shows exactly one note.
   This note does the same.
6. **Compiled/minified artifacts.** `home.html` loads `PoolDetail.compiled.min.js` +
   `translations.min.js`. Editing `PoolDetail.js`/`translations.js` REQUIRES
   `npm run compile && npm run minify` or `test_compiled_assets.js`/`test_minified_assets.js`
   fail.

## Hard constraints (NEVER weakened)

- The note READS `pool.kpis.tvlTrend` + `pool.kpis.historyPoints` + the 071 APY booleans
  only. It NEVER filters, drops, reorders, re-weights, or re-flags a pool, and never
  reads/writes `APY_SANITY_LIMIT`/`DEFAULT_MIN_TVL`/anomaly flags/degen haircut. Trust
  rails byte-untouched.
- Every displayed phrase through `translations.js` EN + natural KO, both added together.
  The percentage is formatted via the en-US `_formatNum` helper (never bare
  `toLocaleString()`), so large trends group correctly (`1,200%`).
- Honest-numbers rule: one-sentence explainable from stored snapshots. Cautious-saver,
  "education not advice" framing; no hype, no "save up/afford/budget". The shrinking case
  is stated plainly (the ICP-relevant risk); the growing case is explicitly NOT sold as a
  guarantee.
- Rendered-Playwright acceptance (2026-07-11 standing decision).

## Acceptance criteria

**A. Render logic (`PoolDetail.js`), placed immediately AFTER the 103 momentum note
(~line 1402), before the Tokens Section.** A calm, full-width note with
`className: 'tvl-trend-note'`, reusing 071's EXACT inline neuro styling
(`background: var(--color-background)`, `borderRadius: var(--neuro-radius-sm)`,
`boxShadow: var(--neuro-shadow-subtle)`, `color: var(--color-text-secondary)`,
`fontSize: var(--font-size-sm)`, `lineHeight: '1.5'`, `padding: '12px 16px'`,
`marginBottom: '20px'`).
- A1. Render NOTHING when ANY of: the 071 volatility boolean is true (same expression the
  088.1/103 notes negate); `pool.kpis` is missing / not an object;
  `typeof pool.kpis.tvlTrend !== 'number'`; `Number(pool.kpis.historyPoints) < 7`;
  `Math.abs(pool.kpis.tvlTrend) < 0.25`. (Null-safe — covers live SEO landings, missing
  data, short windows, and sub-threshold noise.)
- A2. Let `tvl = pool.kpis.tvlTrend`, `hp = Number(pool.kpis.historyPoints)`,
  `pctStr = _formatNum(Math.round(Math.abs(tvl) * 100)) + '%'`.
  - Tier SHRINKING — `tvl <= -0.25`: `t('tvlTrendShrinking', pctStr, hp)`.
  - Tier GROWING — otherwise (`tvl >= 0.25`, since `|tvl| >= 0.25` and not shrinking):
    `t('tvlTrendGrowing', pctStr, hp)`.
- A3. Reads only `pool.kpis.*` + the 071 APY booleans. Rails untouched (A above).

**B. Copy (`translations.js`, EN + natural KO, both added together).** Two keys, calm
cautious-saver "education not advice" framing:
- `tvlTrendShrinking` (fn `(pct, hp) =>`): EN "This pool's deposits have shrunk about {pct}
  over the {hp} days we've tracked it. A pool can keep clearing our $10M size floor while
  quietly losing deposits — worth watching for a garden you plan to hold for years."
- `tvlTrendGrowing` (fn `(pct, hp) =>`): EN "This pool's deposits have grown about {pct}
  over the {hp} days we've tracked it. More deposits isn't a guarantee, but a pool that's
  holding or gaining size is one honest sign of staying power."
- KO: natural (not literal) translations of each, same two keys, in the KO block.
  (`{pct}` is the pre-formatted percent string incl. the `%`, e.g. `"25%"`.)
