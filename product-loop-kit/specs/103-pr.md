# 103 — PR explainer (HIGH tier): rate-momentum note on pool detail

**Item:** 103 · **Risk:** HIGH (user-facing number on the pool-detail render path, trust-rail adjacent)
**Verifier:** PASS, 6/6, HIGH tier independently re-derived · **Ship:** one-commit on the harness-pinned

## Goal
Give the cautious-saver an honest, disclosed read on **which way a pool's rate has been moving** — the
truthful version of "exciting." Rising AND falling both said out loud. This is the second KPI surfaced
from the 087 data layer (after 088.1's steadiness note), on the same pool-detail surface that SEO
arrivals and in-app browsers land on, feeding the card funnel with a trust signal rather than hype.

## Intuition
087's daily CI already computes `kpis.apyMomentum = last − first total-APY` over the retained history
window (percentage points; `null` until ≥2 points). We surface it as a single calm sentence — but only
when it actually *means* something: enough history (≥7 days) and a move big enough to matter (≥0.5pp).
Below that, 088.1's "steady / tracked" note already covers the pool, so momentum stays silent. On a
volatile pool (071 fires), momentum yields entirely — the volatility warning dominates. The whole thing
is a mirror of the 088.1 note: same styling, same guard shape, same test scaffold.

## What changed and why (reading order)

1. **`PoolDetail.js` (+44)** — a new `.rate-momentum-note` element inserted immediately after the 088.1
   `.rate-track-record-note`, before the Tokens Section. It is a sibling conditional in the same render
   list. The guard, left to right:
   - `!(<071 volatility boolean>)` — byte-identical to the divergence expression the 071 and 088.1 notes
     use, so momentum and the 071 "moves a lot" note are mutually exclusive (071 wins).
   - `pool.kpis && typeof pool.kpis === 'object'` — null-safe; live `?pool=` SEO landings carry no kpis
     and render nothing.
   - `typeof pool.kpis.apyMomentum === 'number'` — hides on the `null` (`<2` history points) case.
   - `Number(pool.kpis.historyPoints) >= 7` — a directional read needs a real window (`Number(undefined)`
     → `NaN` → false, so missing historyPoints also hides).
   - `Math.abs(pool.kpis.apyMomentum) >= 0.5` — below a meaningful move, 088.1's steady/tracked copy
     already speaks; no redundant "barely moved" note.
   The body is an IIFE (mirrors 088.1): `mom >= 0.5` → RISING copy, else FALLING copy, delta via
   `_formatApy(Math.abs(mom))`, `hp` passed through. The `|mom| >= 0.5` guard makes the two sign-tiers a
   clean partition (RISING ≥ +0.5 / FALLING ≤ −0.5). Styling is the exact 8-property inline neuro object
   the 071/088.1 notes use — no new class in CSS, no gradient, no one-off. Reads only `pool.kpis.*` +
   `apyBase/apyReward/apyMean30d`; touches **no** rail constant, mutates **no** pool list.

2. **`translations.js` (+4)** — `rateMomentumRising(delta, hp)` and `rateMomentumFalling(delta, hp)` in
   both EN (~L50) and KO (~L675), added together. Cautious-saver "education not advice" framing; the
   falling copy names the decline plainly ("eased down", "Falling rates are normal once reward emissions
   taper"). No "save up / afford / budget", no hype. KO is a natural (non-literal) rendering.

3. **Regenerated artifacts** — `PoolDetail.compiled.js`, `PoolDetail.compiled.min.js`,
   `translations.min.js` via `npm run compile && npm run minify`. `app.compiled.*` regenerated
   byte-identical (no diff). `test_compiled_assets.js` (4/4) and `test_minified_assets.js` (9/9) assert
   the artifacts equal a fresh recompile — not stale.

4. **`test_kpi_momentum.js` (new)** — a rendered-Playwright gate copied from `test_kpi_track_record.js`
   (PORT 8796, selector `.rate-momentum-note`), driving the real `?pool=<id>` pool-detail DOM. D1–D8:
   RISING present + "2.3%" + "30"; FALLING present + "2.3%" + "30"; below-threshold / short-window /
   null-momentum / no-kpis all ABSENT; 071-volatile → momentum ABSENT + volatility PRESENT; `?lang=ko`
   RISING → Korean substring `올랐습니다`; zero page errors. Wired into `package.json`'s test chain right
   after `test_kpi_track_record.js`. Ran 8/8, exit 0 (verifier re-ran independently).

## Deviation from spec (one, test-only)
Spec §D1/D2 illustrated the asserted delta as `"2.30%"`. The render uses `_formatApy` (= app.js
`formatApy`, `maximumFractionDigits:2` with **no** `minimumFractionDigits`), so `2.3` renders `"2.3%"`.
The render logic is spec-exact; only the test assertion was corrected to the actually-rendered `"2.3%"`.
Verified live: `formatApy(2.3) === "2.3%"`.

## Conservative scope (documented, not a deviation)
BACKLOG 103 reads "pool detail/**cards**"; this leg does **pool detail only**, mirroring 088.1 (which did
detail and deferred `?pool=` SEO-landing enrichment). One surface, smallest-change, one-item rule. Card
surfacing stays a follow-up under the open 088 parent (with 104 TVL-trend, 105 SEO deep-link kpis).

## Data reality at ship
With one retained history point, `apyMomentum` is `null` for every pool, so the note renders for NO pool
in production yet. It activates automatically as 087's daily CI accrues ≥7 points and a rate moves
≥0.5pp — same "code handles all cases, data catches up" situation as 088.1 at its ship.

## Measurement
No isolable Mixpanel funnel metric (a trust-signal surfacing on an existing surface, in the 088.1
disclosure lineage). It strengthens the pool-detail→garden→waitlist trust chain; the honest proxy is
"the note renders correct rising/falling tiers once ≥7-point history exists" — testable via the daily CI
snapshot. Render-path HIGH → advisory human visual spot-check (003 pixel gate unshipped).
