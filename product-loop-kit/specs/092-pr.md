# 092 — PR explainer (HIGH tier)

## Goal
The analytics browse must not present 0%/near-0%-yield pools as if they were
attractive yields. A UX-audit screenshot (human, 2026-07-14) showed collateral
assets (CBBTC / WSTETH / WEETH) with huge TVL and a stark **"0%"** *topping* a
TVL-sorted list. This is the prerequisite-pair for 089 (default sort → TVL):
flipping the default to TVL without this fix guarantees those 0% pools land at
the very top of the default grid.

## Intuition
Two independent honest moves, no data hidden:
1. **Order:** in the TVL sort, put pools that actually pay yield above pools that
   don't. Size (TVL) still orders within each group.
2. **Label:** on a no-supply-yield card, replace the meaningless "$0.00/day"
   line with an honest tag — "No supply yield". The real **0.00%** APY number
   still renders (trust rail — we contextualize, never suppress).

## What changed and why (diff in reading order)

### `app.js`
- **Module-level helper** (after `DEFAULT_MIN_TVL`):
  `NO_SUPPLY_YIELD_EPSILON = 0.01` and
  `hasNoSupplyYield(pool) = (apyBase||0)+(apyReward||0) < 0.01`.
  0.01% is the exact cutoff below which `formatApy` (2-dp) renders "0.00%" — the
  population the audit flags. Pure function, reused by sort + render.
- **Three TVL-sort blocks** (token-first ~1689, chain-first ~1760, all-pools
  ~1831): the `if (sortBy === 'tvl') return b.tvlUsd - a.tvlUsd;` body now first
  compares `hasNoSupplyYield` (yielding → 0, no-yield → 1; `noA - noB` puts
  yielding first) and only then falls back to TVL desc. Structurally identical to
  the existing `userSortedApy` anomaly-demote one branch over — same idiom.
  The APY `else` branch and its anomaly-demote are untouched.
- **`renderPoolCard`**: the `.pool-apy-preview` (`$X/day`) div is now conditional
  — `hasNoSupplyYield(pool)` renders `.pool-apy-tag` with `t('noSupplyYield')`;
  otherwise the daily-earnings preview as before. The `.pool-apy-hero` (0.00%)
  and the anomalous-APY (`APY_SANITY_LIMIT`) branch are untouched.

### `translations.js`
- `noSupplyYield`: EN "No supply yield" / KO "공급 이자 없음", added beside `tvl`
  in both `en:` and `ko:` blocks.

### `style.css`
- `.pool-apy-tag`: calm, muted variant of `.pool-apy-preview` — neumorphic tokens
  only, no accent border/gradient/glow. Deviation: spec's `--color-text-tertiary`
  is absent from the design system → substituted `--color-text-secondary`
  (verified present). See `092-notes.md`.

### Generated + test
- `app.compiled.js` / `app.compiled.min.js` / `translations.min.js` /
  `style.min.css` regenerated via `npm run compile && npm run minify`
  (analytics app ships the compiled/min assets — source edits are invisible
  until rebuilt; byte-identity gated by test_compiled/minified_assets).
- `test_zero_yield_demote.js` (new, wired into `package.json`): fixture-routed
  Playwright, drives the real UI, asserts demote-below-yielding + tag present +
  honest 0.00% hero preserved + yielding cards untagged.

## Deviations from spec
Only the CSS token substitution above. Full list in `092-notes.md`.

## Risk
Touches the analytics browse render + sort on the sacred parameterized-URL
surface (`?token=`/`?chain=`) → **HIGH** per NORTH_STAR ("parameterized-URL
behavior … when in doubt → HIGH"). But: no URL/canonical/indexing/SEO-surface
change (which pools appear is unchanged — only intra-result ordering + one honest
label); trust rails untouched (sanity limit, TVL floor, anomaly demote/flags all
unchanged, no number hidden); no new deps; ~50 source lines. Both router paths
still render pool cards (regression test green). No NEVER-list surface touched.
