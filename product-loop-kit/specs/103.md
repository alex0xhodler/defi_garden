## Territory notes (verified in code 2026-07-15 — these BIND the design)

1. **`kpis.apyMomentum` shape (compute-kpis.js:98).** `apyMomentum = round(last.apyTotal -
   first.apyTotal, 2)` over the retained ascending series, i.e. the change in **total APY percentage
   points** across the tracked window. It is `null` when `series.length < 2` (`enough` guard) — so the
   note must null-gate. Positive = rate rose; negative = rate fell. Rounded to 2 decimals.
2. **How `kpis` reach PoolDetail (identical to 088.1).** `PoolDetail` takes `pool` as a prop; it does
   not fetch. In-app browse→detail (`?token=`/`?chain=`) loads `data/pools-snapshot.json`, which CARRIES
   `kpis` → the note renders. A direct `?pool=<id>` deep link loads LIVE `/pools` (no `kpis`) → the note
   hides honestly. SEO deep-link enrichment stays a separate documented follow-up (item 105).
3. **Data reality today.** With one retained history point, every pool's `kpis.apyMomentum` is `null`
   (needs ≥2 points). So the momentum note renders for NO pool today; it activates automatically as
   087's daily CI accrues ≥2 (and, per this spec, ≥7) history points. The code handles every case; the
   data catches up. This matches 088.1's "code handles all tiers; data catches up" reality.
4. **Never double-note with 071.** 071's "moves a lot" volatility note owns the current-vs-30d-mean
   divergence case. The momentum note yields ENTIRELY when 071 fires (the exact same divergence boolean
   used by 088.1), so 071 and the momentum note are mutually exclusive — no note pile-up on a volatile
   pool.
5. **Relationship to the 088.1 track-record note.** The momentum note is ADDITIVE and independent — it
   does NOT edit or gate 088.1's render logic (surgical diff; no coupling). Redundancy is avoided by the
   magnitude gate below: momentum only speaks when there is a *meaningful directional move*
   (`|apyMomentum| >= 0.5` pp). A near-flat pool (which 088.1 would call "steady"/"tracked") produces no
   momentum note, so the two rarely co-fire and never say the same thing.
6. **Compiled/minified artifacts.** home.html loads `PoolDetail.compiled.min.js` and
   `translations.min.js`. Editing `PoolDetail.js`/`translations.js` REQUIRES `npm run compile &&
   npm run minify` (052/053/061/088.1 precedent) or `test_compiled_assets.js`/`test_minified_assets.js`
   fail.

## Hard constraints (NEVER weakened)

- The note ranks/annotates WITHIN pools that already pass the sanity/TVL/anomaly rails — it never
  rescues a filtered pool or overrides a flag. `APY_SANITY_LIMIT`, `DEFAULT_MIN_TVL`, anomaly demotion,
  degen ⅓ haircut untouched. The note reads ONLY `pool.kpis.*` + `pool.apyBase/apyReward/apyMean30d`; it
  never filters, drops, reorders, re-weights, re-flags a pool, and never reads/writes rail constants.
- Every displayed phrase through translations.js EN + natural KO, both added together. Numbers via the
  existing `_formatApy` (consistent with the 071/088.1 notes; en-US pinned).
- Honest-numbers: momentum is explainable in one sentence from stored snapshots (last − first APY over
  the tracked window). Falling rates said out loud. "Education, not advice" framing; no "save
  up/afford/budget", no hype.

## Acceptance criteria

**A. Render logic (`PoolDetail.js`), placed immediately AFTER the 088.1 rate-track-record note
(~line 1358, before the Tokens Section).** A calm, full-width note with
`className: 'rate-momentum-note'`, reusing the EXACT inline neuro styling of the 071/088.1 notes
(`background: var(--color-background)`, `borderRadius: var(--neuro-radius-sm)`,
`boxShadow: var(--neuro-shadow-subtle)`, `color: var(--color-text-secondary)`,
`fontSize: var(--font-size-sm)`, `lineHeight: '1.5'`, `padding: '12px 16px'`, `marginBottom: '20px'`).
Let `volatilityFires` be the exact 071 boolean (`typeof pool.apyMean30d === 'number'` &&
`(apyBase||0)+(apyReward||0) > 0` && `apyMean30d > 0` && `max/min >= 1.5`); `k = pool.kpis`;
`mom = (typeof k.apyMomentum === 'number') ? k.apyMomentum : null`; `hp = Number(k.historyPoints)`.
- A1. Render NOTHING when ANY of: `volatilityFires` is true; `k` missing/not an object; `mom === null`;
  `hp < 7` (a directional read needs a real window — same 7-point threshold as 088.1's steady/tracked);
  `Math.abs(mom) < 0.5` (below a meaningful move, 088.1's steady/tracked copy already covers it — no
  redundant "barely moved" note). Null-safe: covers live SEO landings and single-point history.
- A2. Two tiers on the sign of `mom` (magnitude ≥ 0.5 already guaranteed by A1):
  - RISING — `mom >= 0.5`: `t('rateMomentumRising', _formatApy(Math.abs(mom)), hp)`.
  - FALLING — `mom <= -0.5`: `t('rateMomentumFalling', _formatApy(Math.abs(mom)), hp)`.
  (`hp >= 7` always, so day-count plural is always correct; the delta is formatted via `_formatApy`,
  matching the 071 note's APY formatting — reads as e.g. "climbed about 2.30%".)
- A3. The note NEVER reads/writes rail constants and never mutates the pool list. Rails untouched.

**B. Copy (`translations.js`, EN + natural KO, both added together, placed next to the 088.1 keys).**
Two keys, calm cautious-saver "education not advice" framing:
- `rateMomentumRising` (fn `(delta, hp) =>`): EN "This pool's rate has climbed about {delta} over the
  {hp} days we've tracked it. Rates that rose can slip back just as easily — this page projects on
  today's rate, not the climb."
- `rateMomentumFalling` (fn `(delta, hp) =>`): EN "This pool's rate has eased down about {delta} over the
  {hp} days we've tracked it. Falling rates are normal once reward emissions taper — worth knowing before
  you plan a garden around today's number."
- KO: natural (not literal) translations of each, same two keys, in the KO block. KO substrings the test
  will assert on must be stable and present verbatim in the KO copy.
