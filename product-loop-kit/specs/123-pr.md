# 123 — LOW-tier explainer: north-star instrumentation DEFINE + verify

## Goal
NORTH_STAR.md pivoted (2026-07-23) to pool-detail conversion clicks — `pool_click{source=garden_cta}` +
`pool_click{source=protocol_link}`. Both CTAs already called `Analytics.trackPoolClick(...)` on real
renders; this item's job was to render-verify that (not trust source reading), confirm segmentation props,
document the copy-pasteable Mixpanel query, and audit every `pool_click` emitter for a rename-vs-isolate
call. Analytics-instrumentation-only — LOW tier per NORTH_STAR.md risk policy.

## What changed
1. **analytics.js `trackPoolClick()`** — added `source: clickType` to the emitted `pool_click` payload.
   `click_type` was the only clickType-carrying property before this; NORTH_STAR.md's own definition
   ("`pool_click` events with `source ∈ {garden_cta, protocol_link}`") described a property that didn't
   exist on the wire. `click_type` is kept alongside `source` — no rename, additive only, no dashboards
   built on `click_type` break.
2. **`test_northstar_cta_fires.js`** (new) — rendered-Playwright test covering both pool-detail entry
   paths (`url_direct` via `/?pool=<id>`, `card_click` via `/?token=USDC` grid → card click) × both CTAs.
   Asserts `pool_click`/`pool_view` fire with non-empty `pool_id`/`pool_project`/`pool_chain`/`total_apy`/
   `source`. Wired into `npm test` (package.json).
3. **NORTH_STAR.md** — new "North-star Mixpanel query" subsection under the metric section: exact event
   names (verified from `analytics.js`, not guessed), the Insights/Formulas report recipe, the emitter
   audit, and the rename-vs-isolate decision.
4. **PoolDetail.js / app.js — NOT touched.** `enrichPoolData()` (analytics.js) already attaches pool
   id/project/chain/apy to both `pool_view` and `pool_click`; the call sites needed no changes. No
   compiled/minified-asset regen required.

## Emitter audit (pool_click)
Three call sites, all via `Analytics.trackPoolClick`: `PoolDetail.js:497` (`garden_cta`, north star),
`PoolDetail.js:517` (`protocol_link`, north star), `app.js:2546` (`yield_calculator`, a pool-card
"calculate yield" shortcut into pool-detail — not part of the north star). `source` now fully
disambiguates all three; no case for promoting any to a distinct event name (default conservative choice
taken, per brief).
