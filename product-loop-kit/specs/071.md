## Change (smallest that satisfies)
In `PoolDetail.js` only (analytics-app pool detail):

1. Compute `currentTotal = (pool.apyBase || 0) + (pool.apyReward || 0)`.
2. Divergence trigger: `typeof pool.apyMean30d === 'number' && currentTotal > 0 && pool.apyMean30d > 0 && (Math.max(currentTotal, pool.apyMean30d) / Math.min(currentTotal, pool.apyMean30d)) >= 1.5`. (1.5× ≈ ±50% relative — ignores normal fluctuation, catches the reported 2.8× case. Conservative: never fires on missing/zero data.)
3. When triggered, render ONE calm full-width note inside the expanded `pool-info-content`, immediately after the stats grid, `className: 'rate-volatility-note'`:
   - Copy (single neutral string, both directions): EN ≈ *"This pool's rate moves a lot: {current} right now vs a {mean} 30-day average. Reward emissions change daily — projections on this page use the current rate and will move with it."* KO: natural translation, same meaning.
   - Both numbers through `_formatApy` (en-US pinned). New key `rateVolatilityNote` in `translations.js`, EN + KO together.
   - Styling: existing neuro tokens ONLY, matching the sibling info tiles (`var(--color-background)`, `var(--neuro-radius-sm)`, `var(--neuro-shadow-subtle)`, `var(--color-text-secondary)`). Calm and informational — NO warning glow, NO urgency styling (CLAUDE.md ban-list). No new CSS file; inline style object like every sibling tile in that grid.
4. NOTHING else changes: hero APY, calculator, trust rails (`APY_SANITY_LIMIT`, TVL floor, anomaly flags, degen haircut), router, `?pool=` URL behavior all untouched.
5. Regenerate the shipped artifacts in the SAME change: `npm run compile` (PoolDetail.compiled.js) and `npm run minify` (PoolDetail.compiled.min.js, translations.min.js) — home.html loads only the `.compiled.min.js`/`.min.js`; skipping this ships nothing (061's caught bug).
