# SPEC 260 — Perp Static Page & Markdown Generator (`generate-perp-pages.js`)
**Parent**: Item 260 in `product-loop-kit/BACKLOG.md` | **Risk Tier**: HIGH | **Status**: READY

## 1. Goal
Generate pre-rendered static HTML landing pages (`/perps/<slug>`) + Markdown twins (`/perps/<slug>.md`) + `sitemap-perp-pages.xml` for all major perp markets (Hyperliquid OIL, HYPE, SOL, BTC, Lighter SPCX, Drift SOL).

## 2. Evidence
- AI Search Engines (Perplexity, SearchGPT, Claude) and Google users search specifically for live perp funding rates ("hyperliquid oil funding rate", "lighter spcx long short yield").

## 3. Implementation Plan
1. **Generator `generate-perp-pages.js`**:
   - Reads `data/perps-snapshot.json`.
   - Emits `/perps/<slug>.html` static pages featuring:
     - 2-sentence direct answer opener below `<h1>`: "Hyperliquid OIL current funding rate is +42.1% APY. Shorts receive funding payments from Longs."
     - Live Mark Price, 24h Volume, Open Interest, Funding Yield APY.
     - `Dataset` & `FinancialProduct` `ld+json` schemas.
     - Outbound referral CTA ("Trade on Hyperliquid →") carrying `code=DEFIGARDEN`.
   - Emits Markdown twins (`/perps/<slug>.md`).
   - Wires `sitemap-perp-pages.xml` into the main sitemap index.
2. **Acceptance Tests**:
   - `test_perp_pages.js`: Assert generated HTML and Markdown pages contain direct answer text, schema, and valid referral CTAs.

## 4. Verification
- `node generate-perp-pages.js` runs cleanly.
- `node test_perp_pages.js` passes.
