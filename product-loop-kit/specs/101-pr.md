# 101 — Subscription share link carries the full multi-service mix. HIGH-tier explainer

**Item:** 101 · North-star (viral loop / card funnel) — the subscription share link must reproduce the sender's full `selectedSubs` mix, not just the anchor `goal`.
**Verifier:** PASS, HIGH tier (7/7 criteria, independently re-derived).
**Risk:** HIGH — touches the share-URL wire format (`encodePlanToUrl`/`decodePlanFromUrl` on `planner.js`), the primary north-star viral artifact + parameterized-URL surface. Not on the NEVER list; no trust-rail weakening. Auto-merges under autonomy (c).

## Goal
A user who builds a multi-service subscription garden (e.g. Spotify + Netflix + Claude Pro) and shares the link was sending a link that, on the recipient's open, rebuilt **only the single anchor `goal`** — a different garden than they built. The share link is the north-star artifact (standing decision 2026-07-11: "a UNIQUE WORKING LINK that reproduces the sender's exact setup one-tap on open"), and SUBSCRIPTION is the card funnel's front door. 101 closes the gap so the link rebuilds the exact mix.

## Intuition
This is a **pure serialization gap**, not a modeling one. The app already computes and stores the mix (`selectedSubs`, planner.js:1501; `plan.mix` at 1767/1795) — it just never put it on the wire. The fix is symmetric: encode `selectedSubs` into a `mix` URL param, decode + validate it on arrival, and seed the mix from it. Two hard constraints shape the edges: **no regression** (single-pick / non-subscription URLs must stay byte-identical — no share-URL churn), and **honest degradation** (a hand-edited/garbage `mix` must never crash or seed a bogus service).

## What changed and why (diff in reading order, all in `planner.js`)

1. **`encodePlanToUrl` (+`mixIds` param, ~L903)** — after the existing chain/token block, add the mix serializer. `mix` is written **only** when `goalArchetype(goal)==='subscription'` AND the mix is a real edited/multi set (not the bare `[goal]` anchor: `isAnchorOnlyMix = length===1 && [0]===goal`); otherwise `u.searchParams.delete('mix')`. This is the regression guard — anchor-only, single-pick, and every non-subscription (GROWTH/TARGET) URL stay byte-identical to pre-101. archetype is computed internally from `goal` (a pure function), so no second param is threaded.

2. **`isSubscriptionId` helper (new, ~L925)** — returns true iff an id resolves to a known subscription: a `SUBSCRIPTION_LADDER` rung (L751) or a subscription-archetype `GOAL` (via `goalById`). This is the decode validator — unknown ids are dropped so a hand-edited URL can never seed a bogus service.

3. **`decodePlanFromUrl` (mix parse, ~L968)** — read `mix`, split on `,`, trim, keep only `isSubscriptionId` ids, wrapped in `try/catch` (never throws on garbage → `mix=null`). Added `mix` to **both** returned objects (capital path + monthly path). `null` when nothing valid remains → arrival falls back to the anchor seed.

4. **Bloom mix seeding (~L1537)** — the crux. `selectedSubs` and `mixTouched` are seeded from `props.initialMix` via the **initial `useState` value**, not a first-mount effect: `useState(sharedMix || [])` and `useState(!!sharedMix)`. Why the initializer and not an effect: an effect calling `setMixTouched(true)` would lose a same-commit race to the existing `!mixTouched`-guarded anchor-seed effect (L1506), which reads the stale `mixTouched=false` in the same flush and would clobber the restored mix. Initializing state makes `mixTouched=true` **before first render**, so the anchor effect's guard skips — race-free. This also lets 099's `slideCapital⇄neededCapital` sync recompute coverage from the full restored mix (not the anchor).

5. **Three encode call sites threaded** (share image L1934, copy-link L1963, native-share L1986) — each now passes `selectedSubs` as the trailing arg.

6. **`initialMix` prop (~L4467)** — the App threads `sharedPlan.mix` down to Bloom, reusing the exact seam 060 uses for `initialChain`/`initialToken`. No new plumbing pattern.

7. **`planner.min.js` regenerated** (`npm run minify`); package.json wires `test_share_mix_roundtrip.js` into the `npm test` chain after `test_subscription_mix_seed.js`. No translations touched (zero new strings).
