# 127 — PR explainer (LOW tier)

**Goal.** Remove the raw analyst-score line that item 117.1 added under the pool-detail rate-track-record note. For the cautious-retail-saver ICP, "Rate-stability score 0.5 (vs a ~4% risk-free rate): how steady this pool's yield has been relative to how much it pays — not a measure of principal safety" reads as jargon on the north-star conversion page, not as trust.

**What changed.**
- `PoolDetail.js`: deleted the "Rate-stability Sharpe annotation (117.1)" render block (the `apySharpe`-gated `marginTop:6px` child inside `.rate-track-record-note`). The calm first sentence ("Steady so far… Steadier rates are easier to plan a garden around") is kept unchanged as the note's sole content.
- `translations.js`: removed the now-unused `rateSharpeNote` key from EN and KO together.
- Regenerated `PoolDetail.compiled.js/.min.js` + `translations.min.js` via `npm run compile && npm run minify`.
- `test_kpi_sharpe_annotation.js`: the 117.1 behavior gate now asserts the annotation is ABSENT (was: present), while the parent note + first sentence still render in EN and KO.

**Why drop, not reword.** A qualitative reword would need an invented `apySharpe` threshold to decide what counts as "steady", and the note renders under volatile pools too — so a threshold-free sentence would falsely claim steadiness. Dropping invents nothing and keeps the trust rails honest. `apySharpe` still powers the risk-adjusted sort and planner tie-break; only its pool-detail display line is gone.

**Risk / scope.** LOW: copy/render removal, EN+KO together, diff « 150 lines, no new deps, no trust-rail / router / SEO / out-of-scope touch. Not on the NEVER list. Verified via the updated rendered Playwright gate (4/4) plus sibling `test_kpi_track_record.js` (7/7) and `test_northstar_cta_fires.js` (7/7).
