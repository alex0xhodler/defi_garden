# Spec 111 — Analytics nav + filter-dropdown UI polish

**Status:** SHIPPED (2026-07-15) · **Risk:** HIGH · **Score:** 7.0
**Origin:** human feedback 2026-07-15 on 093's shipped nav — "the data and icons are
very confusing, needs an upgrade" + "these selectors need better hover overlay
controls and UI for [the open-dropdown] state". Human chose **option 1** of the
operator's proposal — strip category-tab icons, keep filter icons.

Written from the BACKLOG row + code audit (no prior spec file). Two parts.

## Why (north-star tie)
The analytics header is the SEO arrival surface feeding the card funnel. Six
competing category glyphs read as noise next to plain text labels; the open
filter-dropdown state uses a CLAUDE.md-**banned** scale-pop hover and a barely-there
selected state. Reducing confusion on the arrival surface is the standing
"fix what makes the product feel bad/untrustworthy" focus.

## Territory notes (code audit 2026-07-15)
- `CATEGORY_TABS` (app.js:96-103) carry an `icon` key into `NAV_ICONS`; rendered at
  app.js:2804-2813 via `navIcon(icon)` inside each `.google-nav-tab` button.
- The 4 filter pills (`.google-filter-btn`, ids `chains-btn/tvl-btn/protocols-btn/apy-btn`)
  in `.google-nav-secondary` (app.js:2820-2856) each also call `navIcon(...)`. Icons
  stay on these. `NAV_ICONS`/`navIcon` remain in use — do not delete them.
- Banned hover: `style.css:1300-1304` — `.global-filter-dropdown .filter-pill:hover:not(.active),
  .filter-chip:hover:not(.active) { transform: translateY(-2px) scale(1.02); }`.
  CLAUDE.md bans scale-pop hovers; replace with neuro lift only (translateY + shadow,
  no scale).
- Selected chip: `style.css:1353-1357` `.global-filter-dropdown .filter-pill.active,
  .filter-chip.active { transform: translateY(-1px); box-shadow: raised; }` — sets no
  background, so fill leaks from the base `.filter-pill.active`/`.filter-chip.active`
  (both already `background: var(--color-primary); color:#fff`) and `.chain-pill.active`
  (`--chain-color`). Make the selected state explicitly, unmistakably filled in the
  dropdown scope while PRESERVING per-chain brand color on chain pills.
- Dropdowns render at document top level, `position:fixed`, `z-index:99999`
  (app.js:3270+). Outside-close today relies on `handleClickOutside` (app.js:1254-1265)
  testing `.filter-dropdown-container` — a class that is rendered NOWHERE, so any
  outside click closes (and clicks inside the panel close too, since each pill's
  onClick already calls `setActiveDropdown(null)`). Works but fragile/implicit.
- Prod loads `app.compiled.min.js` + `style.min.css`. Edit `app.js`/`style.css`, then
  `npm run compile` + `npm run minify`, commit the regenerated
  `app.compiled.js`/`app.compiled.min.js`/`style.min.css`.

## Part A — Primary category rail: drop the icons
- Remove the `navIcon(icon)` call from the `.google-nav-tab` buttons in the
  `CATEGORY_TABS.map` (app.js:2810). Keep the `.google-nav-label` span. Keep
  `NAV_ICONS`/`navIcon`/`CATEGORY_TABS.icon` (still referenced by the filter pills).
- The 4 filter pills keep their icons unchanged.

## Part B — Open filter-dropdown state
1. **No banned scale-pop hover** (`style.css:1300-1304`): replace
   `transform: translateY(-2px) scale(1.02)` with neuro lift only —
   `transform: translateY(-1px); box-shadow: var(--neuro-shadow-raised);` (no `scale`).
2. **Selected chip unmistakable** (`style.css:1353-1357`): the active pill/chip in an
   open dropdown is a solid **filled** control — `background: var(--color-primary);
   color:#fff; font-weight: semibold; box-shadow: var(--neuro-shadow-raised);
   transform: translateY(0)`. Chain pills keep brand color via a follow-on
   `.global-filter-dropdown .chain-pill.active { background: var(--chain-color, var(--color-primary)); }`.
3. **Subtle scrim + explicit outside-click close**: render a `.filter-dropdown-scrim`
   `<div>` only while `activeDropdown` is truthy — `position:fixed; inset:0;`
   `z-index:99998` (just under the `99999` dropdown), subtle theme-aware backdrop
   (light-mode ~`rgba(0,0,0,0.04)`, dark a touch more), fade-in gated by
   `prefers-reduced-motion`, `onClick` → `setActiveDropdown(null)`. New CSS class uses
   neuro tokens / low-opacity only — no gradients, no glow. The existing
   `handleClickOutside` effect stays (belt-and-suspenders); the scrim is the visible +
   robust close affordance.

No new user-facing strings → `translations.js` untouched (EN/KO parity preserved
trivially). Trust rails, the `__APP_MODE` router, and `?token=/?chain=/?pool=`
behavior are untouched.

## Acceptance criteria (rendered Playwright on the real UI)
Extend `test_nav_rail_ia.js` (Part A) and add `test_filter_dropdown_polish.js` (Part B);
wire the new test into the `npm test` chain. Route `icons.llamao.fi` pool-logo loads to a
1×1 fixture (or add to the ignorable pattern) so the sandbox network artifact does not
mask real errors.
1. **A/#4 rewrite**: every `.google-nav-tab` (category tab) contains **zero** `<svg>`;
   every `.google-filter-btn` (filter pill) still contains an inline `<svg>`.
2. Category filtering still works end-to-end (clicking RWA filters the grid, exactly
   that tab `.active`) — the rest of `test_nav_rail_ia.js` stays green.
3. **B — no scale**: with a dropdown open, the computed `transform` of a hovered
   inactive pill contains no `scale(` component (matrix scale ≈ 1).
4. **B — filled selected**: the selected pill/chip's computed `background-color` equals
   the primary (or chain brand) fill and its `color` is white — visually distinct from
   an unselected surface-colored pill.
5. **B — scrim present**: opening a filter renders exactly one `.filter-dropdown-scrim`
   covering the viewport, `z-index` below `.global-filter-dropdown`.
6. **B — outside-click closes**: clicking the scrim removes both the scrim and the
   `.global-filter-dropdown` (`activeDropdown` → null).
7. Zero non-ignorable page errors; flawless in DOM at 360/768/1280 and dark mode.
8. `npm run compile` + `npm run minify` regenerated assets committed; full `npm test`
   green (or pre-existing sandbox-only failures stash-baseline-proved unrelated).
