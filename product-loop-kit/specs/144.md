# 144 — `apyMean30d` renders unclamped: a live pool shows a 36,452% "30d Mean APY" on pool-detail

Status: IN_PROGRESS (2026-07-25) · Score 7.5 · Risk HIGH (render path on the north-star surface, app-code change) · Type BUGFIX
Promoted by the build loop 2026-07-25 (no READY items existed; promotion from documented in-repo evidence, item-074/070 precedent).

## Provenance / evidence (all already in the repo — nothing inferred)
1. **`specs/142-notes.md` §5 (2026-07-25, item 142's root-cause note):** *"`PoolDetail.js` renders `pool.apyMean30d` verbatim through `_formatApy` in the '30d Mean APY' card, gated only on `typeof … === 'number'`, with no sanity clamp — so an absurd value lands in visible pool-detail text exactly like the 122 rate-stability number did."* Item 142 used this as its positive-control injection point and **proved it renders in real Chromium**.
2. **Live confirmation in committed data** (`data/pools-snapshot.json`, 740 rows): pool `201e5f6e-cf75-4d0e-b07f-d58da3cee23a` — balancer-v2 **WSTETH-AAVE**, Ethereum, TVL **$12,412,471** (clears the `$10M` rail, so it is served), `apyBase 0.24482`, `apyReward null`, **`apyMean30d = 36452.38798`**. The pool-detail "30d Mean APY" card therefore renders **36,452.4%** — 36× `APY_SANITY_LIMIT` — on a pool that is **not** anomaly-flagged, because flagging keys off `totalApy` only (`PoolDetail.js:242`, `totalApy = 0.24`). This is not a hypothetical: it is what `/?pool=201e5f6e-cf75-4d0e-b07f-d58da3cee23a` shows today.
3. **Second visible surface:** the 071 rate-volatility note (`PoolDetail.js:1365-1389`) fires on the divergence ratio and quotes the number in prose — *"This pool's rate moves a lot: 0.24% right now vs a 36452.4% 30-day average."*
4. **Bug class precedent = item 122** (P0, SHIPPED): the −900T rate-stability score on the same surface. `specs/122-pr.md` established the fix pattern — *a magnitude render gate*, because the garbage value is finite and `isFinite` alone does not catch it.
5. **NORTH_STAR.md 2026-07-23 PRE-TRAFFIC MANDATE:** the loop's primary job is product quality — "broken/absurd numbers" is the first named bug class. Pool-detail is the north-star surface (`pool_click{garden_cta|protocol_link}`); a 36,452% figure on it reads as "broken" and suppresses exactly the clicks the north star counts.

## The bug in one line
`apyMean30d` is rendered (card + prose) with no sanity bound, so any value DefiLlama reports — including one 36× above `APY_SANITY_LIMIT` — is presented as a trusted fact on the conversion page.

## Fix (mirror 122, surgical)
A single derived sanity boolean in `PoolDetail.js`, used at every `apyMean30d` gate:

```js
// 144: apyMean30d is presented as fact; anything outside the trust rail is not
// presentable. Magnitude gate (not isFinite alone) — 122's precedent: garbage
// values are finite.
const mean30dSane = typeof pool.apyMean30d === 'number' &&
  Number.isFinite(pool.apyMean30d) &&
  pool.apyMean30d >= 0 &&
  pool.apyMean30d <= APY_SANITY_LIMIT_LOCAL;
```

- "30d Mean APY" stat card (`PoolDetail.js:1282`) renders only when `mean30dSane` — honest omission, never a fabricated or clamped number (122 precedent: `null` beats a made-up value).
- The 071 divergence boolean (repeated at `:1368`, `:1396`, `:1444`, `:1490`) uses `mean30dSane` in place of its `typeof pool.apyMean30d === 'number'` term, so the note can never quote a number the card refuses to show. The three mutually-exclusive sibling notes (track-record 088.1, momentum 103, tvl-trend) keep their existing yield-to-071 semantics unchanged and simply become eligible instead — no gap, no crash.
