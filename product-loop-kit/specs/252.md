# SPEC 252 — 301 HTTP Redirect & Canonical Bridge (Parameterized URLs → Static Routes)
**Parent**: Item 252 in `product-loop-kit/BACKLOG.md` | **Risk Tier**: HIGH | **Status**: READY

## 1. Goal
Transfer 100% of historical Google PageRank and search authority from old parameterized URLs (`/?token=SYMBOL`, `/?chain=NAME`) to the corresponding static routes (`/tokens/<slug>`, `/chains/<slug>`).

## 2. Evidence (GSC API Data)
- Google Search Console API performance report over 90 days revealed **100% of impressions and clicks** were on parameterized URLs (`/?token=NFLXX`, `/?chain=Chiliz`, `/?token=PYUSD`).
- Google Inspection API confirmed these pages were flagged as **"Crawled - currently not indexed"** because the old canonical tags pointed to the root homepage (`https://www.defi.garden/`).
- Meanwhile, static URLs (`/tokens/usdc`) were returned as **"URL is unknown to Google"**.

## 3. Implementation Plan
1. **`vercel.json` 301 Redirects**:
   - Add clean 301 redirect rules for simple parameterized queries:
     `/?token=(.*)$` -> `/tokens/$1` (lowercased) when no additional filter parameters (`minTvl`, `poolTypes`, `app`) are present.
     `/?chain=(.*)$` -> `/chains/$1` (lowercased).
2. **`canonical.js` Normalization**:
   - Update `window.__canonicalFor(search)` so that single-token or single-chain queries emit `<link rel="canonical" href="https://www.defi.garden/tokens/<slug>">` and `<link rel="canonical" href="https://www.defi.garden/chains/<slug>">`.
3. **Acceptance Tests**:
   - Create `test_301_canonical_bridge.js` verifying that `canonicalFor('?token=USDC')` returns `https://www.defi.garden/tokens/usdc`.

## 4. Verification
- `node test_301_canonical_bridge.js` passes.
- Inspect `/?token=USDC` in Chrome to verify `canonical` tag points to `https://www.defi.garden/tokens/usdc`.
