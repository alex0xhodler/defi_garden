# 115 — Honest "tend your garden" reminder (calendar .ics) — the missing hook-model trigger leg

**Status:** READY · **Score:** 7.5 · **Risk:** HIGH (new user-facing capability beyond copy/styling) · **Theme:** hook-model retention → card funnel

## Why (evidence — browser-driven discovery 2026-07-15)
`CLAUDE.md`'s hook model: **trigger** = monthly tending + rate-change deltas · **action** = one tap · **variable reward** = real rate movement ("you're 2 weeks ahead of plan") · **investment** = the saved plan. Browser + code audit this run (`reports/2026-07-15-hook-model-discovery.md`):
- **investment** ✓ built (`garden-plan` localStorage, 826-byte plan persisted).
- **action** ✓ built (one-tap plan creation).
- **variable reward** ✓ built — report mode renders "Still on track — your rates are holding steady" / `reportAhead` = "Ahead of plan — rates ticked up since you planted this" (`translations.js:398–399`, `reportStats` `planner.js:378`).
- **trigger** ✗ **entirely unbuilt.** Rendered bloom probe: `trigger: false`. Rendered report-mode probe: `trigger_reminderAffordance: false`. Codebase grep for `Notification` / `serviceWorker` / `remind` / `add to calendar` / `every month`: **nothing.** The variable reward can only ever be seen if the user *spontaneously* remembers to return. A hook loop with no trigger cannot retain — this is the single highest-leverage unbuilt leg of the documented product model.

A no-backend static site can't push/email server-side, but it **can** hand the user an honest, self-service trigger: a downloadable calendar reminder. No dependency (an `.ics` file is plain text via a Blob), no permission prompt, no dark pattern.

## What to build
Add a **"Remind me to tend this monthly"** affordance in **two** places in `planner.js`:
1. At **bloom** (the finished-plan surface, near the existing share row `🔗 Copy your garden link` / `or save as an image`).
2. In **report mode** (the return-visit dashboard), so a returning user can re-arm the reminder.

On tap: generate and download an `.ics` calendar event, entirely client-side:
- `SUMMARY`: reuse/add a string, e.g. "Tend your DeFi Garden — check your rates" (existing `tendGarden` = "Tend your garden" at `translations.js:390`; add a fuller `tendReminderTitle` if needed). EN + natural KO together.
- `DTSTART`: ~30 days out. **Date math must not use bare `Date` in a way that breaks** — mirror the existing `savedAt`/report date handling (`new Date(...)`, `toISOString`); no `toLocaleString()` without `en-US` (house rule).
- `RRULE:FREQ=MONTHLY` so it recurs (honest cadence matching "monthly tending").
- `DESCRIPTION` + `URL`: the plan's **share URL** so the reminder deep-links back into the exact garden (report mode auto-loads). **Reuse `encodePlanToUrl`** (`planner.js:930`) — do not hand-build the URL; the same call the share buttons already use (`planner.js:1964/1993/2016`).
- Trigger the download via a Blob + object URL + a synthetic `<a download>` click (standard, no dep). Filename e.g. `defi-garden-tending.ics`.
- Copy stays calm and honest — "we'll never email you; this adds a private reminder to your own calendar." No urgency, no streaks-pressure.

Styling: neumorphic tokens only, `:active` sink, reduced-motion safe, flawless 360/768/1280 + dark. Reuse the existing share-row button classes rather than inventing a new control style.
