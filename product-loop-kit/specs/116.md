# 116 — Re-share the garden from report mode ("Share my garden" copy-link CTA)

- **Status**: IN_PROGRESS (promoted 2026-07-16 by build loop — no buildable READY item existed)
- **Score**: 7.4
- **Risk**: HIGH (user-facing interactive behavior beyond pure copy/styling; when in doubt → HIGH per NORTH_STAR risk policy — same classification precedent as 115's report-mode control)
- **North star**: DIRECT — `share_link_created → share_link_opened → plan_created` viral-loop closure

## Why (evidence)

`reports/2026-07-15-hook-model-discovery.md` filed three unfiled candidate
follow-ups. Candidate #1 — **"Re-share an 'ahead of plan' garden from report
mode (direct viral-loop closure)"** — is the most north-star-direct of the set.

The share hub (spec 005/024/101) lives only at the **bloom** step, inside the
`GardenBloom`/Planner-local state. **Report mode (`GardenReport`) has no share
affordance at all** — grep/render-confirmed: `gp-report-actions` holds Tend +
Fresh; `gp-report-reminder` holds only the 115 `.ics` tend-reminder. Yet report
mode is exactly where a *returning, engaged* user lands ("Ahead of plan" / "On
track" status pill) — the highest-intent moment in the hook loop, and today it
is a viral dead end: the user can see their progress but cannot re-originate a
share link that rebuilds their garden for a friend.

Standing decision 2026-07-11 (item 024/101): "the link that rebuilds the garden
is the primary artifact ... the working link is what closes the loop." Report
mode already computes that exact link for the tend-reminder
(`encodePlanToUrl(...)` in `reportTendReminder`, planner.js:3374). This item
surfaces it as a one-tap re-share — a new share-origination point in the
retention loop.

## What (smallest change)

Add a **"Share my garden"** copy-link control to `GardenReport`, reusing the
shipped share/copy pipeline. No new share mechanic — extend the existing one to
a new surface.

### Behavior
1. Render a `gp-share-textlink` button (class `gp-report-share-link`) in the
   report footer area, above the existing `.gp-tend-reminder`, with a short
   honest note (reusing `gp-tend-reminder-note` styling — **zero new CSS**).
2. On tap: build `url = encodePlanToUrl(plan.goal, plan.monthly, plan.years,
   plan.persona, plan.capital, plan.fundingMode, plan.deadline, plan.poolFilters,
   plan.mix)` — the identical call `reportTendReminder` already uses.
3. Copy `url` to the clipboard via `navigator.clipboard.writeText` with the
   `textarea` + `execCommand('copy')` fallback (reuse the `doCopyLink` pattern,
   planner.js:2048–2069). Show a transient "Copied!" confirmation
   (`shareLinkCopied`) for ~2s via a local `React.useState`.
4. Instrument: `Analytics.trackShareLinkCreated({ method: 'copy', surface:
   'report', goal: plan.goal, persona: plan.persona })` — guarded by
   `typeof Analytics !== 'undefined'`, same guard the tend-reminder uses. The
   `surface: 'report'` prop separates report-origin shares from bloom-origin
   ones for measurement.

### Copy (translations.js — EN + KO together, natural KO)
- `reportShareCta`: EN "🔗 Share my garden" · KO "🔗 내 정원 공유하기"
- `reportShareNote`: EN "Copies a working link that rebuilds this exact garden for whoever you send it to." · KO natural equivalent
- Reuse existing `shareLinkCopied` ("Copied!" / "복사됨!") for the success state.

### Constraints / reuse (standing decision 2026-07-10 — reuse before inventing)
- Reuse classes `gp-share-textlink`, `gp-report-reminder`, `gp-tend-reminder-note`
  — **no new CSS rules**.
- Additive render only. Does **NOT** touch: `encodePlanToUrl` output for
  existing paths, the `__APP_MODE` router, canonical/parameterized-URL behavior,
  any trust rail (`APY_SANITY_LIMIT`/`DEFAULT_MIN_TVL`/anomaly/degen haircut).
- Regenerate `planner.min.js` and `translations.min.js` (plan.html loads the
  `.min.js` — 061's precedent: unminified-only copy ships nowhere).
- No new dependencies.

## Territory notes
- `GardenReport` is a function component already using `useMemo`; a local
  `React.useState` for the copied flag is safe (same hook context).
- `plan.mix` is the 101 subscription-mix field; passing it through
  `encodePlanToUrl` makes subscription re-shares carry the full mix, consistent
  with 101. Non-subscription plans pass `mix=null` → byte-identical URLs.
- ~~`trackShareLinkCreated` (analytics.js:346) spreads its context arg~~ **FALSE
  PREMISE — corrected attempt 1 (verifier catch)**: `trackShareLinkCreated`
  (analytics.js:346-352) does NOT spread `context` — it hardcodes an emitted
  payload of `{method, goal, persona}` and would silently DROP `surface`, making
  the measurement plan unmeasurable. `trackTendReminderAdded` (line 363) is the
  function that carries `surface`. **Fix**: add `surface: context.surface || null`
  to `trackShareLinkCreated`'s emitted payload (mirroring line 365). Backward-
  compatible: bloom call sites pass no `surface` → emit `surface: null`, which is
  exactly what distinguishes them from report-origin `surface: 'report'`. The
  acceptance test now asserts the emitted `share_link_created` payload actually
  carries `surface:'report'` (patching the bare global `Analytics.track` — item
  044's lesson: `Analytics` is a top-level `const`, a bare global, NOT a window
  property), closing the silent-drop gap.

## Instrumentation & measurement
- Event: `share_link_created { method: 'copy', surface: 'report', goal, persona }`.
- Hypothesis: a re-share affordance at the return-visit high-intent moment adds
  a new share-origination point → more `share_link_created` (surface=report) →
  feeds `share_link_opened → plan_created` closures.
- Metric to move: weekly `share_link_created` with `surface=report`; downstream
  `share_link_opened → plan_created`.
- Window: 14 days from first real report-surface share. Decision rule: keep if
  report-surface shares > 0 with no guardrail regression; below 30 events →
  "insufficient data" (traffic-gated: north star is 0 until distribution posts).
- NOTE: like every current build, this is **traffic-gated** — no report-surface
  shares can fire until the human posts the 069 distribution packs. This ships
  the mechanism so it exists when traffic lands; it does not manufacture traffic.
