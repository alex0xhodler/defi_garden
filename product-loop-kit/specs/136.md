# 136 — P0 BUG: primary "Garden this pool" CTA + TOTAL APY clipped invisible on pool-detail at 360px

- **Score**: 9.2 · **Risk**: MEDIUM (CSS-only, but north-star render path) · **Status**: IN_PROGRESS (2026-07-24)
- **Source**: heartbeat product-audit 2026-07-24 (rendered repro, screenshots in scratchpad); BACKLOG row 136.
- **North star**: pool-detail conversion clicks — `pool_click{source=garden_cta}` ("Garden this pool") + `pool_click{source=protocol_link}`. This bug makes the #1 CTA (`garden_cta`) **un-tappable for the entire mobile-width device class**, so it is a direct north-star blocker, not cosmetic.

## The bug
On pool-detail at 360px viewport (light AND dark, reproduced 2/2 pools — SUSDS `d8c4eff5…`, uniswap-v3 WETH-USDC `b99bcdf5…`):
- The primary **"Garden this pool"** CTA and the **TOTAL APY** value are clipped invisible. Only "TOTAL AP" (cut mid-word) + the secondary protocol button survive.
- **NOT a page-scroll issue**: body `scrollWidth` 352 ≤ 360. The overflow is clipped *inside* the hero card, so a `scrollWidth`-based test passes today and misses the whole class.

## Root cause (computed-geometry confirmed)
- `.pool-action-card` (pool-detail-styles.css `~766`) has `min-width: 260px` + `padding: 20px` (= ≥300px) and has **no mobile override**.
- The hero card (`PoolDetail.js:325-335`) is an inline-styled `div.pool-hero-card` with `padding: 32px` and `overflow: hidden`.
- The `@media (max-width:768px)` block (pool-detail-styles.css `~964`) turns `.pool-hero-content` into a column and gives `.apy-display-hero` `min-width: auto !important` — **but never touches `.pool-action-card`**. So the action card stays ≥300px wide inside a hero card whose inner content width at 360px is ~296px (viewport − container padding − 2×32px hero padding), and the ~60px overflow is clipped by `overflow:hidden`.
- Structural / min-width-driven; predates item 125's longer CTA copy (125 otherwise render-verified PASS).

## Fix
Add `.pool-action-card` to the existing `@media (max-width:768px)` block in `pool-detail-styles.css` with a mobile override that lets it shrink to the column width:
```css
.pool-action-card {
  min-width: auto !important;
  width: 100%;
  box-sizing: border-box;
}
```
Neumorphic-token-only, reuses the exact idiom already applied to `.apy-display-hero` two rules above. No new selectors, no JS change, no trust-rail surface. There are two `.pool-action-card` render sites (`PoolDetail.js:464` hero, `:1535` sticky calculator CTA) — both benefit from the same override; verify neither regresses.

Then regenerate the minified sheet production actually loads:
- `home.html:149` loads `pool-detail-styles.min.css` (analytics mode) — run `node minify-assets.js` and commit the regenerated `pool-detail-styles.min.css`.
