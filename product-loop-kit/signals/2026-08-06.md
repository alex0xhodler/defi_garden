### NEW, first on record — P0 `grid-token`: the analytics grid boots dead
Two findings on one surface, causally linked:
- `[P0] grid-token :: page-error` — `pageerror: React is not defined` **plus**
  `console.error: TypeError: Cannot read properties of undefined (reading 'some') at getPoolTypeShared
  (PoolDetail.compiled.min.js:1:1510)`
- `[P1] grid-token :: dead-end` — `valid grid query rendered no .pool-card within 10s`

**Mechanism — confirmed from the error signature, not inferred from resemblance:**
`PoolDetail.compiled.min.js` line 1 opens with ONE comma-separated `var` statement:
`var{useState:useState,useEffect:useEffect}=React,LENDING_PROTOCOLS=[…],…,RWA_PROTOCOLS=[…]`.
If `React` is not yet defined, the destructuring throws, so **every later declarator in that same statement
never assigns** — while `function getPoolTypeShared(pool)` is a hoisted function declaration and stays
callable. Its first array read is `RWA_PROTOCOLS.some(…)` (verified in the minified body). That predicts
*exactly* the observed pair: `React is not defined`, then `reading 'some'` inside `getPoolTypeShared`.
The two errors are one event, and they can only occur in that order for that reason.

**Why React can be missing:** `home.html:178-179` load React and ReactDOM with `defer`; `home.html:350-364`
appends `PoolDetail.compiled.min.js` via `document.createElement('script')` from an inline script at the
end of `<body>`. Dynamically inserted scripts are **async by default** — nothing orders them against the
deferred tags. The comment at `home.html:343-347` documents an ordering guarantee only *between*
`PoolDetail.compiled.min.js` and `app.compiled.min.js` (the `onload` chain); there is **no guarantee at all
against the deferred React/ReactDOM/translations tags**. `onload` still fires on a script that threw, so
`app.compiled.min.js` loads on top of the wreckage and calls into it.

**Frequency, measured, and stated at its real strength:** 1 occurrence in 1 contended full run (83
surfaces); **0 of 6** isolated `runAudit({only:['grid-token']})` repeats, each of which instead produced
grid-token's usual 2 occlusion findings. So: contention-dependent, NOT reproducible on demand, and NOT
dismissible — the mechanism is structural in `home.html`, which is the same file prod serves. Prod
frequency is **unknown and currently unmeasurable** (see the prediction above).
