- `error_stack` = `ReferenceError: translations is not defined\n  at https://www.defi.garden/planner.min.js:1:70405\n  at planner.min.js:1:70644\n  at Object.useMemo (react-dom.production.min.js) …`
- `page_url` = **https://www.defi.garden/** (bare `/` = the **planner, funnel-top page**) · `$browser` = Chrome · desktop · en-US · `can_recover` = true
- **Root cause (read-only triage):** `planner.js:795` (`makeT()`) dereferences the bare global `translations[lang]` during a React `useMemo`. `home.html` loads `translations.min.js` then `planner.min.js`, both `defer` (ordered) — so `translations` is normally defined first. This throws only when `translations.min.js` fails to define the global at makeT time (transient load failure / blocked request / deploy race). `can_recover=true` means the global error handler caught it, but the planner render broke for that session → a **funnel-top failure**. Latent fragility (line 795 is old code), not a new regression.
- **NOT premature to act:** NORTH_STAR names `error_occurred` a guardrail and "a bug at a funnel step outranks any experiment." n=1 / recoverable → defensive hardening, not an emergency, but it is the top BUILD item (broken beats persuasion). → filed as backlog **082**.
