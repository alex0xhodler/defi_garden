## Design Specificity Verdict
The approved list view IS the product's voice — a quiet ledger. The surfaces around it haven't caught up: the search state is a Google-2015 pastiche (double-ring glowing shell, all-caps gradient rocket button), the card view is the pre-Quiet skin (20px bold titles, per-card accent links), and the pool hero wears a terminal costume (mono 900 H1, caps accent chip). Deterministic scan: 1 advisory (`PoolDetail.js:1184` radius 6px off-scale) — the detector reads markup, not the CSS where the real drift lives; treat its near-silence as a false negative, not a clean bill. No browser overlay (no mutation-capable browser tool in this harness; static Playwright renders used as the visual evidence instead).

## Priority issues (each with the one-line fix)

1. **[P1] Degen CTA violates three standing bans at once** — `.search-button.feeling-degen`: uppercase + letter-spacing badge case, gradient fill, `::before` shimmer sweep, −2px lift hover; it makes the degen path the loudest element on a trust-first product. *Fix: Quiet secondary button (neutral bg, 1px border, sentence case "I'm feeling degen"), delete shimmer/gradient/lift; feature and ⅓-haircut rail untouched.*
2. **[P1] Search shell wears three focus rings** — `.search-input:focus` gets accent border + `--ui-focus-ring` + a legacy `outline: 2px` (style.css:3311); with autofocus the page loads glowing. *Fix: drop `.search-input:focus` from the legacy outline rule; the token border+ring is the sanctioned Quiet treatment.*
3. **[P1] Footer says "Made with AI & Degen Love." on every money surface** — names the persona the ICP is explicitly not, in the trust position (spec 240 already approves the fix). *Fix: "Powered by DefiLlama API. Education, not advice." via translations, EN + natural KO, grep-zero on app surfaces.*
4. **[P1] Card view never received round 3a** — `.pools-grid .pool-symbol` 20px vs list 15px, accent "View & calculate →" spent once per card (~9 blue at rest per screen), APY size bump at ≤640px, letter-spaced TVL label. *Fix: inherit the list type scale, mirror the list's quiet-link CTA (secondary at rest, accent on hover), constant APY size.*
5. **[P2] Pool hero costume + broken chips** — mono/900 H1, "STAKING" caps accent chip, trust chips wrap internally ("✓ / Verified", "Risk Assessment: / Low" each split across two lines). *Fix: body stack H1 at 700, sentence-case neutral chip, `white-space: nowrap` on chips + `flex-wrap` on the row.*
6. **[P2] Search buttons off the control grid** — ad-hoc ~54px height + radius-lg vs the 40px/radius-md system; title-case "Token Search". *Fix: control-h/radius-md + sentence case.*

## What's working
- The list view + control band genuinely read as one system — the target the rest should snap to.
- Trust rails are visible design, not just logic (anomaly flags, honest 0.00%, haircut notes).
- Footer hub links + DefiLlama attribution are the right bones; only the sign-off is off-voice.

## Persona red flags
- **Tomoko (cautious saver, project ICP)**: the loudest button on her first screen is an all-caps rocket telling her to be a degen; the footer jokes about "Degen Love" under money numbers. Both erode the only currency this product has.
- **Sam (a11y)**: triple focus indication on the search input is noise, not clarity; chips whose text wraps mid-chip read poorly at 200% zoom.
- **Alex (power user)**: card→list toggle switches visual language entirely — feels like two products.

## Minor observations (deferred)
- Global −2px lift-hover block (style.css ~5377) still covers pool-card/theme-toggle; list is approved as-is, leave for a dedicated pass.
- `.metric-card:hover` lift + `.apy-value-large` boxed number on pool detail — increment (b) proper.

- "Ethereum" chain name in pool hero is accent-at-rest (One Voice violation) — inline style, cheap but composition-adjacent; deferred to (b).
