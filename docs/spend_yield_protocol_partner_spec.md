# Spend Your Yield — B2B Protocol Integration & Partnership Spec

## 1. Overview & Strategic Value Proposition
The **Spend Your Yield** SDK (`<SpendYieldWidget />`) enables any DeFi protocol, automated liquidity manager (ALM), or yield aggregator to offer an embedded **"Deposit & Auto-Pay Subscriptions"** rail directly on their frontend.

### For Partner Protocols (Morpho, Aave, Aerodrome, Pendle, LST Issuers):
- **Sticky Liquidity & TVL Lockup:** Users depositing to fund continuous subscription cards (e.g. OpenAI, Cursor, AWS, Netflix) rarely withdraw their underlying principal, creating high-duration, low-churn TVL.
- **Differentiated Frontend Utility:** Transforms passive yield farming into tangible real-world consumption without requiring the protocol to build banking, card issuing, or compliance rails.
- **Interchange & Fee Revenue Sharing:** Partner frontends can earn an optional basis-point share of the card interchange and Boosted Mode spread generated by their users.

## 2. Technical Integration Architecture

### A. Embeddable Frontend Component (`<SpendYieldWidget />`)
```tsx
import { SpendYieldWidget } from '@defi-garden/spend-yield-sdk';

export function VaultDepositView({ vaultAddress }) {
  return (
    <SpendYieldWidget
      partnerId="morpho-curator-alpha"
      network="base" // 8453
      underlyingToken="USDC"
      vaultAddress={vaultAddress}
      defaultSubscription={{
        name: "ChatGPT Plus",
        amountMonthlyUsd: 20.00
      }}
      onCardIssued={(cardData) => console.log('Card provisioned:', cardData.id)}
      onDepositSuccess={(txHash) => console.log('Deposit tx:', txHash)}
      theme="dark" // 'dark' | 'light' | 'custom'
    />
  );
}
```

### B. Smart Contract & Proxy Layer
1. **ERC-4626 / Vault Proxy:**
   - User deposits USDC into an isolated non-custodial proxy (`SpendYieldProxy`).
   - Proxy deposits USDC into the selected underlying vault (e.g., Morpho Blue, Aave v3, Aerodrome gauge).
   - Principal shares are locked in the user's proxy address.
2. **Keeper Delegation & Event Emission:**
   - Emits `YieldSweepConfigured(address indexed user, address indexed vault, uint256 targetMonthlyUsd, address cardContract)`.
   - The decentralized Keeper daemon observes the event and registers harvest schedules on Base.
3. **Invariable Non-Custodial Solvency Rule:**
   $$\Delta \text{Principal} \equiv 0$$
   Only realized net yield above the deposited principal is harvested and swept to the user's Rain virtual card balance.
